# 3D 与场（v0.8）

第四界面模式**「3D 与场」**：three.js WebGL 渲染后端与 2D Canvas 层**并存**（唯一新增渲染后端）。
3D 对象与 2D 文档**共享同一份状态与撤销栈**（同一 store；`?mode=space` 或工具条标签进入）。

---

## 视图与交互

- 相机：**透视 / 正交**可切换；轨道控制（左键旋转、右键平移、滚轮缩放）；**z 轴向上**（数学约定）；
- 坐标轴（x 红 / y 绿 / z 蓝，负半轴细灰）+ z=0 网格平面；
- 渲染循环**限帧 ~30fps**（低端/软件渲染设备上控制 CPU 占用）；
- **切平面模式**：左键在曲面上拖动移动切点（射线拾取）；空白拖动仍为旋转视图；
- **上下文丢失处理**：阻止默认的 `webglcontextlost` 并显示提示，`webglcontextrestored` 后自动重建全部对象；
- **能力检测**：无 WebGL（软件/受限环境）时显示降级提示，其余模式不受影响。

## 对象类型（四种，均存文档：可撤销、可保存、可分享）

| 类型 | 内容 |
|---|---|
| **曲面** `surface3d` | 显式 `z = f(x,y)` / 参数曲面 `(x,y,z)(u,v)` / 隐式 `F(x,y,z)=0`（Marching Cubes）/ 旋转体（母线 `r(x)` 绕 x 轴）/ **正多面体与棱柱棱锥**（three 内置几何） |
| **空间曲线** `curve3d` | 参数曲线 `(x,y,z)(t)` 或**洛伦兹吸引子**（RK4，经典参数 σ=10, ρ=28, β=8/3） |
| **向量场** `field3d` | 3D 场 `(u,v,w)(x,y,z)` 或 z=0 平面 2D 场；箭头场 + 可选流线（RK4）；**散度/旋度着色** |
| **ODE 解** `ode2d` | `y′ = f(x,y)`：**欧拉（橙）/ 改进欧拉（绿）/ RK4（蓝）同图对比** + 方向场 |

### 对象管理（v3.1.3）

- **点击对象行直接编辑**：列表里的名称是**行内输入框**——点击即选中该对象（编辑区联动）且可直接改名；编辑区标题显示「编辑：<对象名>」；
- **隐式曲面空警告**：若 F 在包围盒内**恒正/恒负**（F = 0 无解）或全部非有限，Marching Cubes 不会产生任何三角面（表现就是“添加成功但没画面”）——面板会显示警告、实际取值范围 `F ∈ [min, max]` 与修正建议（等值面写法「表达式 = 常数」/ 调整范围 / 改用 `z = f(x, y)`）。实例：`sqrt(x²+y²+z²+1/(1+x²))` 恒 ≥ 1，属无解；写成 `sqrt(x²+y²+z²+1/(1+x²)) = 2` 即可得到一张变形球面。

预设库覆盖验收要求：`sin(x)·cos(y)`、马鞍面、抛物面、圆锥、隐式球、单叶双曲面、椭球/环面/莫比乌斯带（参数）、旋转体 ×2、正多面体 ×5、棱柱/棱锥；洛伦兹/螺旋/环面纽结；旋转场/径向场/鞍点/谐振子相图/捕食者-猎物；ODE 五例。

### 自定义方程（自动识别，v3.1.1）

添加区选「**自定义方程（自动识别）**」后直接粘贴方程，无需先选类型（实时提示识别结果）：

| 写法 | 识别为 | 例子 |
|---|---|---|
| `z = f(x, y)` 或直接 `f(x, y)`（不含 z） | 显式曲面 | `z = x^2 - y^2` |
| 含 z 的等式 | 隐式曲面（归一为 F = 左 − 右，Marching Cubes） | `x^2 + y^2 + z^2 = 1` |
| 含 z 但无等号 | 隐式曲面 F(x, y, z) = 0（原样） | `x^2 + y^2 + z^2 - 1` |
| `r = f(x)` | 旋转体（母线绕 x 轴，x ∈ [−π, π]） | `r = 1 + cos(x)` |
| `x = f(u, v); y = g(u, v); z = h(u, v)`（分号；用 u、v） | 参数曲面（u、v ∈ [0, 2π]） | `x = sin(u)*cos(v); y = sin(u)*sin(v); z = cos(u)` |
| `x = f(t); y = g(t); z = h(t)`（分号；用 t） | 空间曲线（t ∈ [0, 2π]） | `x = cos(t); y = sin(t); z = t/5` |

细节：分号支持中文「；」；两段参数写法时 z = 0（平面上的空间曲线）；全角等号「＝」自动归一；一个方程最多一个等号（多了会报错且不添加）；参数域/包围盒/步数等添加后可在对象面板调整。

输入框下方提供**快捷输入**（v3.1.2，同 2D 曲线面板）：常用函数 `sin()` `cos()` `tan()` `ln()` `exp()` `√` `|x|` `x²` `π`（函数按钮插入后光标在括号内，可连续输入，如点 `sin()` 再点 `y` → `sin(y)`）与变量 `x` `y` `z` `u` `v` `t`、「；分段」按钮；点击在光标处插入，非自定义模式自动隐藏。

### 参数化预设（系数可调）

预设分两类：

- **固定预设**（如莫比乌斯带默认带宽、正多面体）：添加后可直接编辑表达式；
- **参数化预设**：添加时在对象上记录**参数绑定**（`template: { presetId, params }`），面板「预设参数」区
  显示系数滑块，**拖动实时重算表达式**（preview 不入历史，松手一步撤销）；参数随文档保存/分享（序列化往返已测）。

| 对象 | 可调参数 |
|---|---|
| 曲面 | 平面 a/b/c；椭球半轴 a/b/c；z=a·sin(bx)·cos(cy)；马鞍面 a/b；抛物面 a；圆锥 a；隐式球 R（范围随 R 缩放）；单叶双曲面 a/b/c；环面 R/r；莫比乌斯带宽 w；旋转体 a/b |
| 曲线 | 洛伦兹 σ/ρ/β；螺旋线半径/螺距 |
| 场 | 捕食者-猎物 α/β/γ/δ |

## 着色与色图

- 三种着色模式：**单色**（对象色）/ **高度**（顶点 z 值 × 色图）/ **法向**（法线→RGB）；
- 色图：**viridis / plasma / coolwarm / gray**（控制点线性内插）——即「自定义色图」选项；
- 曲面支持透明度与颜色调整。

## 辅助元素

- **等高线投影**：显式曲面在底面 `z = zMin` 投影 Marching Squares 等值线（1~12 层）；
- **切平面**：切点 $(x_0, y_0)$ 处显示平面 $z = f + f_x·Δx + f_y·Δy$、切点球与法向箭头；
  **偏导 ∂f/∂x、∂f/∂y 由 v0.2 符号求导编译**（`differentiate` → `compile`），与数值中心差分的一致性由单测验证（误差 < 1e-6）；
- 正多面体：正四/六/八/十二/二十面体 + N 棱柱 / N 棱锥。

## 二重积分与坐标参照（v2.1）

- **二重积分**：面板输入 $f(x,y)$ 与矩形区域 $[x_0,x_1]\times[y_0,y_1]$，按复合 Simpson（每方向 128 段，共 129² ≈ 1.7 万采样）求数值解；
  结果显示区域坐标与采样数；区域内出现非有限取值（如 $1/(x^2+y^2)$ 在原点）会计数并提示「结果不可靠」；
- **区域可视化**：场景中以蓝色半透明底面 + 边框 + 四角竖线标出积分区域（z=0 平面，随相机旋转），「清除区域」移除；
- **坐标参照增强**：x/y/z 轴带箭头锥头与轴端字母标签；轴线抬高 0.02 避免与网格中心线（z=0）深度冲突；
  默认视角（相机后移 + fov 55°）保证三轴与箭头全部入画。

## 表面算法与取舍

### 网格生成

| 类型 | 三角化 | 法线 |
|---|---|---|
| 显式 | 规则网格（每轴 8~256 段） | 解析梯度 `(−f_x, −f_y, 1)`（中心差分） |
| 参数 | (u,v) 规则网格 | `∂P/∂u × ∂P/∂v`（中心差分） |
| 旋转体 | (x, θ) 网格 | `∂P/∂θ × ∂P/∂x`（径向外） |
| 隐式 | Marching Cubes（见下） | F 的梯度（中心差分） |
| 多面体 | three 内置几何（平面着色） | 面法线 |

无效值（NaN/∞）区域：顶点保留但**相关三角形整体跳过**，不产生破面。

### Marching Cubes 的取舍（重要）

标准 MC 的 256 情形表存在**面歧义**（需渐近判定器消歧）。本实现采用 MC 家族的**四面体分解**
（Marching Tetrahedra）：每个立方体单元拆为 6 个四面体，逐四面体按 16 种符号组合提取三角形。

- **优点**：无歧义、实现小、易正确性验证（单测：球面顶点到原点距离标准差 < 1e-3）；
- **代价**：单元内三角形数略多（跨单元顶点仍按网格边去重）；
- **规模**：64³ 提取 < 2 秒（性能单测）；上限 128³ 与 400 万三角形保护（触发截断标记）。

### LOD 策略

- 分辨率由**对象参数**控制（8..256 每轴，默认 96）——不同函数需求差异 100 倍（`sin(10x)` vs `x+y`），交由用户按需调节；
- 隐式曲面在场景层上限 96³；
- 无动态 LOD（本版简化）：渲染循环限帧 30fps 保证低端设备可用；需要更高帧率时降低分辨率。

## 导出

- **截图 PNG**：渲染器快照（`preserveDrawingBuffer` 直接 `toBlob`）；
- **旋转 GIF**：绕 z 轴一圈取帧（**帧数 12~72** 与**播放速度 2~30 fps** 可调，面板滑块），
  每帧 `readPixels` → 降采样 ≤ 420 宽 → gifenc 逐帧量化编码；
  导出期间显示遮罩（相机临时旋转取帧），**完成后自动恢复原视角**；
  一次点击只导出一个文件（防重复导出循环由请求 token 消账保证）。

## 已知限制

| 项 | 说明 |
|---|---|
| WebGL 兼容性 | 需 WebGL1/2 支持；无 WebGL 环境（旧集显/禁用）显示提示并停用 3D 模式，其余功能不受影响 |
| 大网格性能 | 256×256 显式网格 ≈ 13 万三角形：独显流畅；软件渲染（如 headless SwiftShader）建议 ≤ 128 |
| 隐式曲面分辨率 | 64³ 约数万三角形；128³ 可达百万级，交互帧率下降（触发截断保护时面板无提示，以三角形数为准） |
| 固定步长 ODE | 三种积分器均为固定步长；**刚性方程**（如 y′=−100y）需要小步长或自适应方法（本版未实现，属已知限制） |
| 参数曲面法线朝向 | 随参数化方向（材质双面渲染规避视觉问题） |
| 等高线鞍点 | 用单元中心值消歧（近似给出其中一种拓扑） |
| 旋转 GIF 成本 | 36 帧 + 逐帧量化，约数秒；大场景建议先降分辨率 |
| 集显降级 | 能力检测 + 限帧 + 分辨率可调；不提供自动降级（无 WebGL 则明确提示不可用） |
