# 表达式语法规范（v0.2）

本文档面向使用者描述表达式引擎支持的完整语法。

> **所有示例均经自动化验证**：下文 `expr-verify` 与 `expr-error` 代码块会被测试
> `src/expr/docs-examples.test.ts` 逐一执行（验证值一致性 / 报错行为）。
> `expr-verify` 行格式：`表达式 [@ 变量=数值, ...] -> 期望值`（相对误差 < 1e-9）。

---

## 1. 数字字面量

- 整数与小数：`42`、`3.14`、`.5`
- 科学计数法：`1e-3`、`2e3`、`1.5E+2`
- **科学计数法与常量 e 的消歧规则**：只有当 `e`/`E` 后**紧跟数字**，或**紧跟 `+`/`-` 且再跟数字**时，
  才构成科学计数法；否则 `e` 视为自然常数：
  - `2e3` = 2000
  - `2e` = `2 * e` ≈ 5.4366
  - `2e+3` = 2000（科学计数法）
  - `2e + 3` = `2*e + 3` ≈ 8.4366（加空格可消除歧义）

```expr-verify
2e3 -> 2000
2e -> 5.43656365691809
2e+3 -> 2000
2e + 3 -> 8.43656365691809
2e+x @ x=1 -> 6.43656365691809
1e-3 * x @ x=1 -> 0.001
.5x @ x=2 -> 1
```

## 2. 标识符与变量

- **变量**：单个字母（大小写敏感），如 `x`、`y`、`t`、`k`；`θ` 是 `theta` 的别名
- **常量**：`pi`、`e`、`phi`、`tau`；`π`→`pi`、`φ`→`phi`、`τ`→`tau`
- **已知名称优先最长匹配**：函数名（`sin`、`log10`…）与上述常量名作为整体识别；
  其余连续字母会**拆分为单字母变量**：
  - `xy` = `x * y`
  - `pix` = `pi * x`
  - `sinx` 会被识别为 `sin` 与 `x`，随后报错提示"函数需要括号"（写 `sin(x)`）

```expr-verify
xy @ x=2, y=3 -> 6
x2 @ x=3 -> 6
pix @ x=1 -> 3.141592653589793
sin(θ) @ theta=0 -> 0
```

## 3. 运算符优先级（从低到高）

| 级别 | 运算 | 结合性 | 示例 |
|---|---|---|---|
| 1 | `=` `!=` `<` `<=` `>` `>=`（比较；顶层赋值见 §5） | 左 | `x < 0` |
| 2 | `+` `-` | 左 | `a - b - c` |
| 3 | `*` `/` `%` | 左 | `a / b / c` |
| 4 | **隐式乘法**（相邻因子） | 左 | `2x`、`(x+1)(x-1)` |
| 5 | 一元 `+` `-` | 右 | `-x`、`--x` |
| 6 | `^`（幂） | **右** | `x^2^3` = `x^(2^3)` |
| 7 | 后缀 `!`（阶乘） | — | `x!`、`2^3!` |
| 8 | 函数调用、括号、原子 | — | `sin(x)`、`(...)` |

**与数学惯例一致的两条关键规则**：

- `-x^2` = `-(x^2)`（一元负号低于幂）
- `x^2^3` = `x^(2^3)`（幂右结合）

```expr-verify
x^2^3 @ x=2 -> 256
-2^2 -> -4
2^3! -> 64
-2x @ x=3 -> -6
2^-2 -> 0.25
x!! @ x=3 -> 720
```

## 4. 隐式乘法

相邻的"因子"之间可省略 `*`。规则与消歧决策：

| 写法 | 含义 | 说明 |
|---|---|---|
| `2x` | `2*x` | 数字后跟变量 |
| `3sin(x)` | `3*sin(x)` | 数字后跟函数 |
| `2(x+1)` | `2*(x+1)` | 数字后跟括号 |
| `(x+1)(x-1)` | `(x+1)*(x-1)` | 括号相邻 |
| `sin(x)cos(x)` | `sin(x)*cos(x)` | 函数调用相邻 |
| `xy` | `x*y` | 单字母变量拆分 |
| `x2` | `x*2` | 变量后跟数字 |
| `pi(2)` | `pi*2` | 常量视作数值参与 |
| `2 3` | **错误** | 两个数字字面量直接相邻必须显式写运算符 |
| `2^2 3` | **错误** | 左侧以数字字面量结尾时同理 |

**优先级**：隐式乘法（级别 4）高于显式 `* / %`（级别 3），因此：

- `1/2x` = `1/(2x)`
- `2x^2` = `2*(x^2)`

```expr-verify
2x + 3 @ x=4 -> 11
(x+1)(x-1) @ x=3 -> 8
1/2x @ x=4 -> 0.125
2x^2 @ x=3 -> 18
3sin(x) @ x=1.5707963267948966 -> 3
```

## 5. 比较运算与赋值

- 比较运算 `=` `!=` `<` `<=` `>` `>=` 的结果为 `1`（真）或 `0`（假）；涉及 NaN 的比较为 `0`
- **顶层**形如 `单变量 = 表达式` 的语句是**参数定义**（Assignment 节点）；其余位置的 `=` 保持比较语义
- 多条语句可用 `;` 分隔（如 `a = 3; b = 2; y = a*x + b`）

```expr-verify
2 < 3 -> 1
sqrt(-1) < 1 -> 0
a = 3 -> 3
x^2 = 4 @ x=2 -> 1
```

## 6. 分段函数

格式：`{条件: 值, 条件: 值, ...}`

- 条件值为非 0 且非 NaN 时取该分支；
- 没有任何分支命中时结果为 `NaN`；
- 分段函数可参与任意运算，分支值本身也可以是分段函数。

```expr-verify
{x < 0: -x, x >= 0: x} @ x=-5 -> 5
{x < 0: -x, x >= 0: x} @ x=2.5 -> 2.5
{0: 5, 1: 7} -> 7
{sqrt(-1): 1, 1: 2} -> 2
```

| `asin` `acos` `atan` | `asin(x)` … | 反三角，定义域外为 NaN |
| `atan2` | `atan2(y, x)` | 四象限反正切 |
| `sinh` `cosh` `tanh` | `sinh(x)` … | 双曲 |
| `asinh` `acosh` `atanh` | `asinh(x)` … | 反双曲 |
| `exp` | `exp(x)` | e 的幂 |
| `ln` `log` | `ln(x)`、`log(x)` | **自然对数**（二者等价） |
| `log` | `log(x, base)` | 任意底对数 |
| `log2` `log10` | `log2(x)` … | 常用对数 |
| `sqrt` `cbrt` | `sqrt(x)`、`cbrt(x)` | 平方根 / 立方根（负数可行） |
| `pow` | `pow(x, y)` | 同 `x^y` |
| `abs` `floor` `ceil` `round` `sign` | `abs(x)` … | 取整与符号（`round` 半值向上，JS 语义） |

| `mod` | `mod(a, b)` | 数学取模（同 `%`） |

## 9. 边界行为约定（不是实现细节，是规范）

| 表达式 | 结果 | 含义 |
|---|---|---|
| `1/0` | `Infinity` | 绘图需要画渐近线 |
| `0/0` | `NaN` | 该点断开 |
| `ln(-1)`、`sqrt(-1)` | `NaN` | 实数域外（v0.9 再引入复数） |
| `tan(pi/2)` | 有限大数（≈1.6e16） | **不是** Infinity；采样器需检测"函数值突变" |
| `0^0` | `1` | 与主流计算器一致 |
| `(-8)^(1/3)` | `NaN` | 负底非整数指数；请用 `cbrt(-8)` |
| `-7 % 3` | `2` | 数学取模，符号跟随除数 |
| `7 % -3` | `-2` | 同上 |
| `x % 0` | `NaN` | — |
| `(-1)!` | `NaN` | 负整数是 Gamma 极点 |
| `4.5!` | ≈52.3428 | 非整数用 Gamma 延拓 |
| `gamma(0)` | `NaN` | 极点 |

```expr-verify
1/0 -> Infinity
-1/0 -> -Infinity
0/0 -> NaN
ln(-1) -> NaN
0^0 -> 1
-7 % 3 -> 2
7 % -3 -> -2
5! -> 120
(-1)! -> NaN
4.5! -> 52.34277778455352
gamma(0) -> NaN
```

## 10. 错误信息

错误均包含**行列位置、原文指示符、期望与实际、修复提示**。例如 `sin(x)) + 1` 会报告第 7 列的多余 `)`，
并提示"括号可能多余"。以下写法都是错误：

```expr-error
sin(x)) + 1
2 3
2^2 3
sin x
sin()
{}
{1: 2
[1+2]
x @ 1
```
