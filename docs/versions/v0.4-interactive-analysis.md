## 工作内容

### 1. 追踪游标

鼠标沿曲线滑动，实时显示：

- 当前点 `(x, y)` 坐标
- 一阶导 `f'(x)`（用 v0.2 的**符号求导**结果，不是数值差分）
- 二阶导 `f''(x)`
- **曲率半径**（可视化为内切圆更佳）
- 该点切线斜率与法线

**吸附行为**：光标靠近曲线时吸附到曲线上最近点，而不是简单取同 x 坐标（后者在多值曲线上失效）。

### 2. 切线动画

拖动切点，切线随之滚动，同时显示：

- 切点坐标
- 斜率数值
- 切线方程（KaTeX 排版）

> 用途：讲"导数的几何意义"。这是数学教学中最直观的一个演示。

### 3. 求根（零点）

- 算法：**牛顿法**（快）失败时回退到**二分法**（稳）
- 在可见视窗内**找出所有零点**，而非最近一个
- 零点是复根时（重根）需检测并特殊处理

### 4. 曲线求交

- 两条曲线的交点，在可见范围内全部找出
- 显示交点坐标（KaTeX）
- 支持"交点吸附"

### 5. 定积分

- 拖拽左右端点选择区间 `[a, b]`
- 区间内填充阴影
- 数值显示：**自适应 Simpson 法**求积 + 解析解（若 v0.2 能做出来）
- 显示 $N$ 次细分的误差估计

### 6. 黎曼和动画

四种模式：**左端点 / 右端点 / 中点 / 梯形**

- 矩形（或梯形）数量 `n` 从 **1 动画过渡到 100**
- 实时显示 $n$ 与当前近似值、真实值、误差
- 动画可暂停、单步、拖拽进度条

> 用途：直观展示"极限"这个概念。

### 7. 泰勒展开

- 输入函数与展开点，逐项叠加
- 显示 n = 1, 3, 5, 7, 9... 项的逼近效果
- 动画展示逼近过程
- 显示当前展开式（KaTeX）

### 8. 工具抽象（架构重点）

上述功能不该是散落的 `if` 分支。本版要建立**可叠加的"工具"抽象**：

```
Tool = {
  id, name, icon,
  activate(), deactivate(),
  onPointerMove(), onPointerDown(), onKeyDown(),
  drawOverlay(ctx, viewport)
}
```

同一时刻只激活一个主工具，但允许叠加（如"追踪游标 + 显示切线"）。

**这个抽象是 v0.5 图论工具、v0.8 3D 工具的基础。**

## 验收标准

### 功能验收

- [ ] 追踪游标：在 `sin(x)` 上滑动，显示的 `(x, y)` 与预期误差 < 1e-6；`f'(x)` 在 `x=0` 处约为 1（误差 < 1e-6）
- [ ] 追踪游标在**多值曲线**（如参数方程圆）上也能正确吸附
- [ ] 切线动画：拖动切点，切线与曲线始终相切（目视 & 数值双重验证）
- [ ] 求根：`x^3 - x` 在 `[-2, 2]` 内找出 **3 个**零点（-1, 0, 1），不遗漏不重复
- [ ] 求根：`x^2`（重根）能检测到并在文档中说明行为
- [ ] 曲线求交：`sin(x)` 与 `cos(x)` 在 `[-2π, 2π]` 内找出**全部 4 个**交点
- [ ] 定积分：$\int_0^{\pi} \sin(x)dx = 2$，数值结果误差 < 1e-9
- [ ] 黎曼和：`n` 从 1 到 100 的动画流畅；`n=100` 时中点法逼近误差 < 0.01
- [ ] 泰勒展开：`sin(x)` 在 0 点展开到 9 项，在 `[-π, π]` 内与原函数目视无法区分
- [ ] **同一时刻只激活一个主工具**，切换工具时旧工具状态正确清理
- [ ] 所有工具均不写入撤销栈（工具是"查看"行为，不改变文档）

### 质量验收

- [ ] 追踪游标的坐标更新延迟 **< 16 ms**（跟随鼠标不卡顿）
- [ ] 黎曼和 `n=100` 动画保持 **≥ 30 fps**
- [ ] 求根/求交在 1 秒内返回（可见范围内的常规函数）
- [ ] 数值算法有明确的最大迭代次数，**不会死循环**
- [ ] 牛顿法在导数接近 0 时能正确回退到二分法（有测试用例覆盖）
- [ ] 工具切换 100 次无内存泄漏（监听器正确解绑）

### 文档验收

- [ ] `docs/tools.md` —— 每个工具的使用说明与限制
- [ ] 数值算法说明：选型理由、收敛条件、失败回退策略
- [ ] 明确记录已知限制（如重根检测、隐函数求交的支持程度）

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **追踪游标用"同 x 取点"** | 在参数方程、极坐标、多值函数上完全失效。必须做**最近点求解** |
| **求根用网格扫描** | 会漏掉窄峰内的根，且随缩放不稳定。用**符号分析 + 数值细化**结合 |
| **黎曼和动画每帧重算** | `n=100` 时若有 100 个矩形逐个重算会掉帧。要增量更新 |
| **工具状态泄漏** | 切换工具忘记解绑事件监听是高发 bug。**必须有统一的生命周期管理** |
| **积分用朴素 Simpson 固定步长** | 在振荡函数上误差大。用**自适应** Simpson |
| **把工具操作写入撤销栈** | 会让 `Ctrl+Z` 行为变得难以预测。工具是查看行为，不应入栈 |
| **数值结果不做误差显示** | 用户会以为 `2.0000001` 是精确值。**必须显示有效位数或误差** |

## 验收方式

```bash
pnpm test src/math/numeric      # 数值算法
pnpm test src/tools
pnpm dev                        # 逐个工具手工验证
```

**人工确认项（逐个走一遍）**：

1. 在 `sin(x)` 上滑动游标，读数是否与直觉一致
2. 拖动切线，切线是否始终相切
3. `x^3-x` 求根，是否找到 3 个
4. `sin(x)` 与 `cos(x)` 求交，是否找到 4 个
5. 黎曼和动画跑一遍 n=1→100，是否流畅且直观
6. 泰勒展开逐项叠加，逼近过程是否平滑
