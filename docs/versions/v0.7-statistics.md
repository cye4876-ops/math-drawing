## 工作内容

### 1. 数据导入

| 来源 | 说明 |
|---|---|
| **粘贴 CSV/TSV** | 从剪贴板直接粘贴，自动识别分隔符与表头 |
| 文件导入 | 拖拽 .csv / .tsv 文件 |
| 手工输入 | 表格编辑器，支持增删行列 |
| 生成数据 | 从分布抽样、从函数生成（`y = f(x) + noise`） |

**要求**：导入时能处理缺失值、非数字列、千分位、不同小数分隔符。

### 2. 散点图与回归

| 回归类型 | 方法 |
|---|---|
| **线性** | 最小二乘（QR 分解，不用正规方程——数值更稳） |
| 多项式 | 指定阶数，最小二乘 |
| 指数 | `y = a·e^(bx)`，对数线性化 |
| 对数 | `y = a + b·ln(x)` |
| 幂 | `y = a·x^b` |
| 自定义 | 用户提供模型，非线性最小二乘（Levenberg-Marquardt） |

**必须同时显示**：

- 拟合曲线（叠加在散点图上）
- 拟合方程（KaTeX）
- **R²、调整 R²、残差标准误**
- **残差图**（与散点图联动）
- 可选：置信带、预测带

### 3. 分布曲线

| 分布 | 类型 |
|---|---|
| 正态 | 连续 |
| t 分布 | 连续 |
| 卡方 | 连续 |
| F 分布 | 连续 |
| 二项 | 离散 |
| 泊松 | 离散 |
| 均匀 / 指数 | 连续 |
| Beta / Gamma | 连续 |

**交互**：

- 拖动参数（μ、σ、n、p、λ...）实时看曲线变化
- **拖拽高亮概率区域**，实时显示面积数值
- 显示分位数（拖拽端点求 `P(X < x)`）
- 双分布对比（叠加显示）

### 4. 直方图与核密度估计

- 直方图：**分箱数自动选择**（Freedman-Diaconis 或 Sturges 规则），也可手动
- 核密度估计（KDE）：核函数可选（高斯/Epanechnikov），**带宽可用 Silverman 规则自动选择**
- KDE 与直方图叠加显示

### 5. 模拟与概率演示（动画）

| 演示 | 内容 |
|---|---|
| **大数定律** | 抛硬币频率随试验次数收敛到 0.5，实时曲线 |
| **中心极限定理** | 从任意分布抽样求均值，样本量增大时均值分布趋于正态 |
| **蒙特卡洛求 π** | 随机撒点，落在圆内的比例逼近 π/4 |
| **自助法（Bootstrap）** | 重抽样分布演示 |
| 随机游走 | 一维/二维，多条轨迹同时展示 |

**动画要求**：可调速度、可暂停、可重置，显示当前统计量。

### 6. 描述统计面板

- 均值、中位数、众数、标准差、方差
- 四分位数、**箱线图**
- 偏度、峰度
- 相关系数（Pearson / Spearman）
- 数据表格视图（可排序）

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **线性回归用正规方程** | $\beta = (X^TX)^{-1}X^Ty$ 在病态矩阵上数值不稳。**必须用 QR 分解或 SVD** |
| **KDE 带宽拍脑袋** | 带宽过大过平滑、过小全是毛刺。用 Silverman 规则自动选择 |
| **直方图分箱拍脑袋** | 同样的数据不同分箱会给出完全不同的视觉结论。用成熟规则 |
| **大数定律动画每帧重算全部历史** | 10 万次试验会卡死。**增量更新累加量** |
| **分布函数自己硬编码近似公式** | t/卡方/F 分布的分位数没有初等闭式。需用**不完全贝塔/伽马函数的数值实现**，这部分要认真写并测试 |
| **CSV 解析忽略边界** | 引号内的逗号、BOM、CRLF、中文编码——都要处理 |
| **散点图用 DOM 渲染** | 10 万点会崩。**必须走 Canvas** |
| **统计模块污染绘图文档模型** | 数据是独立层，不要塞进曲线列表。保持模型清晰 |
