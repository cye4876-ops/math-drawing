## 工作内容

### 1. 位图导出（PNG）

- 分辨率选择：1x / 2x / 4x（或自定义 DPI）
- 透明背景选项
- 导出范围：当前视窗 / 指定区域 / 自动包含全部内容
- **注意**：Canvas 导出需处理 devicePixelRatio，否则得到模糊图

### 2. 矢量导出（SVG）

- 曲线导出为 `<path>`，**不是位图嵌入**
- 坐标轴、网格、标签、标注文本全部矢量化
- 文本使用 `<text>` 元素（保持可编辑）
- **关键**：导出时重新按矢量精度采样曲线，而不是复用屏幕采样的点（屏幕点太稀，放大后有折角）

### 3. 动画导出

- 格式：**GIF**（兼容性好）与 **MP4/WebM**（体积小、质量高）
- 来源：黎曼和动画、泰勒展开动画、图算法逐步演示、参数变化动画
- 帧率与时长可配置
- 实现：GIF 可用 `gif.js` 类方案；视频用 `MediaRecorder` 或 `CCapture` 思路

### 4. LaTeX TikZ 导出（**本版核心价值**）

| 图形类型 | 输出目标 |
|---|---|
| 函数曲线 | **PGFPlots** 的 `\addplot` 代码 |
| 参数/极坐标 | PGFPlots 的 `parametric` / `polaraxis` |
| 图论 | **tikz-network** 或纯 TikZ 的 `\node` / `\draw` |
| 标注与标签 | TikZ `\node` |

**这是 AST 价值的兑现点**：因为我们有表达式的符号结构（v0.2 的 AST），可以直接输出 `\addplot {sin(deg(x))};`，而不是输出一堆离散坐标点。**后者在论文里毫无意义。**

输出要求：

- 生成的代码**必须能直接在 LaTeX 中编译通过**
- 可选：输出为独立可编译的最小文档（方便用户直接测试）
- 保留颜色、线型、标签

### 5. 公式标签（KaTeX）

- 图形内可插入公式标注，用 KaTeX 渲染
- 支持数学模式与位置锚定（点、曲线上的点、区域）
- 导出 SVG 时公式需转为路径或保留为文本（提供选项）

### 6. URL 状态编码（分享链接）

- 把**完整文档状态**编码进 URL：曲线表达式、参数值、视图范围、图结构、标注
- 不需要后端：压缩 + Base64（建议用 LZ 类压缩，避免 URL 过长）
- 打开链接即完整还原

**前提**：文档模型必须完全可序列化。v0.2 的参数系统、v0.3 的曲线状态、v0.5 的图数据都必须参与序列化。

### 7. 文档保存/载入

- 保存为本地 JSON 文件
- 从文件载入
- （可选）自动保存到浏览器存储，防丢失

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **SVG 复用屏幕采样点** | 屏幕 1000 px 宽采 1000 点，放大到 A4 打印就有明显折角。**必须按矢量精度重采样** |
| **TikZ 输出坐标点列表** | 失去了 AST 的全部价值，且代码冗长不可读。**必须是符号形式** |
| **生成的 LaTeX 编译不过** | 最常见的失败：转义遗漏（`_`、`^`、`%`）、包未声明、数学模式错误。**必须有实际编译的自动化测试** |
| **URL 过长** | 图结构较大的状态会超出浏览器限制。**必须压缩**，并对超长情况有降级提示 |
| **PNG 模糊** | devicePixelRatio 未处理。这是高频 bug |
| **动画导出内存爆掉** | 逐帧存 bitmap 会吃光内存。需**流式编码**而非全缓存 |
| **序列化遗漏字段** | 新增功能忘记加入序列化 → 分享链接丢数据。**需要往返一致性测试兜底** |

## 验收方式

```bash
pnpm test src/export
pnpm test src/export/url-state    # 往返一致性
```

**TikZ 编译验证（必须实际执行）**：

```bash
# 导出示例 .tex 后
pdflatex export-test.tex
# 断言：退出码 0，生成 PDF，无 warning 级别的错误
```

**人工确认项**：

1. 导出 SVG → 浏览器打开 → 放大 10 倍 → 确认曲线仍平滑
2. 导出 TikZ → 在 LaTeX 中编译 → 对比 PDF 与屏幕显示
3. 生成分享链接 → 换个浏览器打开 → 确认完整还原
