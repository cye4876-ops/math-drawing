## 工作内容

### 1. 四种曲线类型

| 类型 | 形式 | 算法 |
|---|---|---|
| **显函数** | `y = f(x)` | 自适应采样 |
| **隐函数** | `F(x, y) = 0` | **Marching Squares**（先固定网格分辨率，后续可选自适应细化） |
| **参数方程** | `(x(t), y(t))` | 按弧长或曲率自适应采样 |
| **极坐标** | `r = f(θ)` | 转换为参数方程后采样 |

### 2. 自适应采样（本版最难的部分）

**朴素做法的失败模式**：等距采样 1000 个点——曲率大的地方不够密（画成折线），平坦的地方浪费；`tan(x)` 的渐近线两侧被连成一条竖线。

**要求的做法**：

1. 递归细分：先均匀取 N 个种子点
2. 对每段检查误差准则（曲率变化、中点偏离弦距离、函数值突变）
3. 超阈值则二分细分，直到达到精度或深度上限
4. **不连续检测**：相邻两点函数值符号相反且绝对值都很大时，判定为渐近线，**断开而非连线**
5. 对每个采样点记录"是否有效"（`NaN` / `Infinity` 处标记为断点）

**性能约束**：单条曲线采样 + 绘制必须在 **16 ms** 内完成（60fps 预算）。

### 3. 视觉呈现

- 自动取色：多条曲线按色环分配，保证相邻曲线颜色可区分
- 线型：实线、虚线、点线
- **渐近线检测并以虚线标出**
- 网格：主刻度 + 次刻度，极坐标网格，对数坐标网格
- 坐标轴：可移动、可隐藏，端点箭头

### 4. 视图控制

| 操作 | 行为 |
|---|---|
| 滚轮 | **以光标位置为锚点缩放**（不是以画布中心） |
| 拖拽 | 平移 |
| 精确输入 | `x ∈ [-10, 10]`、`y ∈ [-5, 5]` |
| 等比模式 | 锁定 x/y 比例（圆看起来是圆） |
| 坐标类型 | 直角 / 极坐标 / 对数 |

### 5. 多曲线管理

- 曲线列表：增删改、显示/隐藏、重命名、排序
- 每条曲线状态：表达式、颜色、线型、采样精度、可见性
- **整个文档状态可序列化**（v0.6 分享链接的基础）

## 验收标准

### 功能验收

- [ ] 四种曲线类型全部可用：`sin(x)`、`x^2+y^2-4`（隐函数圆）、`(cos(t), sin(t))`（参数）、`r=1+cos(θ)`（心形线）
- [ ] 多条曲线可同时显示，颜色可区分
- [ ] 滚轮缩放以**光标位置**为锚点，光标下的数学坐标保持不动
- [ ] 等比模式下，`x^2+y^2=4` 看起来是正圆而非椭圆
- [ ] 精确视图输入生效
- [ ] 曲线可单独隐藏/显示
- [ ] 文档状态可导出为 JSON 并完整还原

### 质量验收 —— 病态函数基准（**本版的核心验收手段**）

必须先用 JSXGraph 跑一遍下列函数，**截图存档作为基准图**，然后我们的实现对照：

| 函数 | 必须正确表现的特征 |
|---|---|
| `tan(x)` | 渐近线处**断开**，不出现竖直连线 |
| `sin(1/x)` | 靠近 0 处高频振荡被正确捕捉，不是一团糊 |
| `x*sin(1/x)` | 在 0 附近收敛到 0，且振荡可见 |
| `1/(x^2-1)` | 在 x=±1 处两条渐近线，断开 |
| `sqrt(x)` | x<0 区域完全不绘制 |
| `ln(x)` | x≤0 区域完全不绘制 |
| `floor(x)` | 阶梯清晰，台阶处垂直（不斜切） |
| `abs(x)/x` | x=0 处断开，不是从 -1 直连到 1 |
| `exp(-x^2)` | 钟形曲线平滑 |
| `x^2` 在 x∈[1e5, 1e5+10] | 极端缩放下仍能画出 |

**判定标准**：逐条与 JSXGraph 基准图比对，**特征一致即通过**（不要求像素级相同）。

其他质量项：

- [ ] 单条曲线采样 + 绘制 **< 16 ms**（1080p，普通函数）
- [ ] 同时显示 10 条曲线，总帧时间 **< 33 ms**
- [ ] 滚轮缩放**无可感知延迟**（< 50 ms 内画面更新）
- [ ] 病态函数不导致死循环或栈溢出（采样深度必须有上限）
- [ ] 极值缩放下（1e-10 ~ 1e10）不崩溃，刻度仍可读

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **自适应采样写错但不自知** | 最危险的陷阱。**必须建立基准图对照机制**，否则会一直在错误的底座上开发 |
| **递归深度失控** | `sin(1/x)` 在 0 附近会无限细分。**必须有最大深度上限与最小像素间隔** |
| **渐近线判定用"值是否 Infinity"** | 不够——`tan(pi/2)` 返回 1.6e16 而非 `Infinity`。要用**函数值突变幅度**判定 |
| **刻度算法随缩放抖动** | 参考文献里的 nice-number 算法，别自己拍脑袋 |
| **devicePixelRatio 处理遗漏** | 会导致线宽模糊、细线消失 |
| **曲线状态散落各处** | 必须一开始就用统一的文档模型，否则 v0.5、v0.6 都要返工 |
| **对隐函数期望过高** | Marching Squares 在细结构上会漏。**接受这个限制并写进文档**，不要试图用固定网格画 `sin(1/x)` 级别的隐函数 |
