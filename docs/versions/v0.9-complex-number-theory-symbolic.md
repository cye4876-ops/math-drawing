## 第一部分：复变函数

### 工作内容

**1. 定义域着色（Domain Coloring）**

把复函数 `f(z)` 的：
- **相位**（幅角）映射为色相
- **模长**映射为明度/饱和度

这样一眼能看出零点、极点、分支割线。这是复分析可视化的标准手段。

- 支持 `sin z`、`exp z`、`Γ(z)`、`ζ(z)`、多项式、有理函数
- 可切换色图（标准 hsv / 改进的高对比色图）
- 网格线叠加（等相位线与等模线）—— **极大提升可读性**
- 缩放平移

**2. 特殊可视化**

| 功能 | 说明 |
|---|---|
| **Möbius 变换动画** | 拖动参数看圆/直线如何映射为圆/直线 |
| **黎曼面预览** | 至少对 `sqrt(z)`、`log(z)` 展示多值结构（3D 或分层显示） |
| **保角性演示** | 显示正交网格在映射后仍正交 |
| **积分路径** | 沿路径的可视化（留数定理演示） |

### 验收标准

- [ ] `f(z) = z` 的域着色为平滑色轮
- [ ] `f(z) = (z-1)/(z+1)` 在 z=-1 处显示极点特征，z=1 处显示零点特征
- [ ] `f(z) = sqrt(z)` 显示分支割线
- [ ] 等相位网格线与等模网格线正确叠加
- [ ] Möbius 变换动画流畅，几何性质正确（圆→圆）
- [ ] 复平面 1024×1024 分辨率下渲染 **< 100 ms**
- [ ] 参数拖动实时更新 **≥ 30 fps**
- [ ] Gamma / Zeta 函数在已知零点附近显示正确特征

## 第二部分：数论与离散可视化

### 工作内容

| 功能 | 说明 |
|---|---|
| **Ulam 螺旋** | 自然数螺旋排列，素数高亮；可缩放观察对角线规律 |
| **素数分布** | `π(x)` 阶梯函数与 `x/ln x` 对比；素数间隙分布 |
| **模运算图案** | `(i*j) mod n` 网格、乘法表图案、中国剩余定理可视化 |
| **Sacks 螺旋** | 素数标注的极坐标螺旋，突出显示素数的螺旋臂 |
| **康威生命游戏** | 可编辑初始状态、播放/暂停/单步、速度调节、常见图案预设（滑翔机等） |
| **曼德博 / 朱利亚集** | 复平面逃逸时间算法，可调迭代次数与着色 |
| **Collatz 序列** | 单个序列的轨迹可视化 + 序列长度热力图 |
| **素数的其他可视化** | 素数螺旋、素数路径、高斯素数 |

### 验收标准

- [ ] Ulam 螺旋在 1000×1000 网格下正确显示，素数对角线可见
- [ ] `π(x)` 与 `x/ln x` 的对比曲线正确
- [ ] 生命游戏：滑翔机预设能正确移动（周期 4，每周期位移 1 格）
- [ ] 生命游戏：1000×1000 网格，**≥ 30 fps**
- [ ] 曼德博集正确显示（迭代次数可调，边界细节随迭代增加而清晰）
- [ ] Collatz：从 27 出发的序列长度正确（已知为 111 步）
- [ ] 所有可视化可导出（复用 v0.6）

## 第三部分：符号计算

### 工作内容

| 功能 | 说明 |
|---|---|
| **化简** | 合并同类项、因式分解、三角恒等变换（有限子集） |
| **多项式** | 因式分解（有理根、二次因子）、展开、除法、最大公因式 |
| **方程求解** | 线性、二次（含复数根）、可因式分解的高次、简单超越方程 |
| **不等式求解** | 解集区间 + **区间可视化** |
| **求导** | v0.2 已有，本版扩展到高阶导与偏导 |
| **积分** | **仅做有限子集**：幂函数、初等函数表、换元法、分部积分 |
| **极限** | 简单极限（多项式比、洛必达的有限情形） |
| **LaTeX 输出** | 把 AST/符号结果渲染为 LaTeX（与 v0.6 联动） |

### ⚠️ nerdamer 的使用方式（重要）

- 稳定版 `1.1.13` 停在 2021-11，五年未更新
- 作者 2026-09 重启，TypeScript 重写，`2.0.0-rc`（**Apache-2.0**），新增化简/因式分解/极限/Laplace 变换
- **用法**：做**差分测试**——同一批表达式分别跑 nerdamer 与自研实现，比对结果
  - 它准的地方：参考其算法
  - 它错的地方（CAS 在边界情况出错是常态）：用自研规则覆盖
- **不允许**让它成为符号计算的唯一实现

### 验收标准

**正确性（必须有单元测试）**

| 测试 | 预期 |
|---|---|
| `factor(x^2-1)` | `(x-1)(x+1)` |
| `expand((x+1)^3)` | `x^3+3x^2+3x+1` |
| `solve(x^2+1=0)` | `x = ±i`（复数根） |
| `solve(x^3-6x^2+11x-6=0)` | `x = 1, 2, 3` |
| `simplify(sin(x)^2+cos(x)^2)` | `1` |
| `integrate(x^2)` | `x^3/3 + C` |
| `limit(sin(x)/x, x->0)` | `1` |
| 与 nerdamer 差分测试 | **≥ 95% 结果一致**；不一致的逐条记录并判定谁对 |

**其他**

- [ ] 不等式解集在数轴上正确可视化（开/闭区间区分）
- [ ] LaTeX 输出可被 KaTeX 正确渲染，且与 v0.6 导出一致
- [ ] 符号计算在 **1 秒**内返回（常规表达式）
- [ ] 无法求解时给出清晰提示，而非错误结果或崩溃

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **域着色色图选错** | 差的色图会让零点极点难以区分。用经过验证的高对比色图 + 网格线叠加 |
| **曼德博集每帧全量重算** | 拖动时卡死。需**渐进式渲染**（先粗后细）或 WebWorker |
| **生命游戏用 DOM** | 大网格必崩。**必须 Canvas**（或 WebGL） |
| **把 nerdamer 当唯一实现** | 它五年未更新的稳定版有已知 bug。**必须差分测试** |
| **符号化简不收敛** | 反复应用规则可能无限循环。**必须有规则应用次数上限** |
| **符号运算超时无保护** | 用户输入恶意表达式会卡死浏览器。**必须有超时** |
| **文档不写"不支持什么"** | 用户会以为这是 Mathematica，然后失望。**必须明确边界** |
| **Ulam 螺旋只画小范围** | 范围太小时规律不可见。**默认范围要足够大**（至少 200×200） |

1. 域着色看 `(z^2-1)/(z^2+1)`，零点与极点是否一眼可辨
2. Ulam 螺旋放大，素数对角线是否清晰
3. 生命游戏跑滑翔机，是否按预期移动
4. 曼德博集放大边缘，细节是否随迭代增加而清晰
5. `solve(x^2+1=0)` 是否给出复数根
6. 拿 10 个自己熟悉的表达式测符号计算，记录错误
