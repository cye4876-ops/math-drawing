## 工作内容

### 1. WebGL 渲染后端

- 引入 **three.js**（本轮唯一新增依赖）
- 与既有 2D Canvas 层**并存**，不是替换
- 相机：透视 / 正交可切换
- 交互：旋转、缩放、平移，支持轨道控制与自由视角
- 光照：至少一个方向光 + 环境光，可选阴影

**架构要求**：3D 视图作为一个**新的面板/标签页**，与 2D 视图共享同一份文档状态与撤销栈。切换视图不丢失状态。

### 2. 曲面绘制

| 类型 | 形式 | 算法 |
|---|---|---|
| **显式曲面** | `z = f(x, y)` | 三角网格，网格分辨率可调 |
| **参数曲面** | `(x(u,v), y(u,v), z(u,v))` | 三角网格 |
| **隐式曲面** | `F(x, y, z) = 0` | **Marching Cubes** |
| **旋转体** | 曲线绕轴旋转 | 由 2D 曲线生成 |

**着色方式**：

- 按 z 值着色（高度图）
- 按法向量着色
- 按函数值/梯度着色
- 自定义色图（viridis、plasma 等）

**网格分辨率自适应**：远处粗、近处细（LOD），避免高分辨率下掉帧。

### 3. 辅助元素

- **等高线投影**：在底面投影 `z = f(x,y)` 的等高线（对理解曲面形状极有帮助）
- **可拖动切平面**：拖动切点，切平面实时跟随，显示偏导数 `∂f/∂x`、`∂f/∂y` 与梯度
- 坐标轴、网格平面、刻度
- 剖面切片：用平面切割曲面看截面

### 4. 空间解析几何

- 点、向量（箭头）、直线、平面
- 二次曲面：椭球、双曲面、抛物面、锥面
- 多面体：正多面体、棱柱、棱锥
- 两平面的交线、点到平面距离等计算

### 5. 向量场

| 可视化 | 说明 |
|---|---|
| 箭头场 | 二维/三维，密度与长度可调 |
| 流线 | 沿场积分得到的曲线 |
| **散度着色** | 用颜色表示 $\nabla \cdot \mathbf{F}$ |
| **旋度着色** | 用颜色表示 $\nabla \times \mathbf{F}$ |
| 场线动画 | 粒子沿流线运动的动画 |

### 6. 微分方程

- **方向场**：一阶 ODE `y' = f(x, y)` 的斜率场
- **解曲线**：欧拉法、改进欧拉法、**Runge-Kutta 4 阶**，同图对比三种方法的差异
- **相图**：二维自治系统 `(x', y') = f(x, y)` 的轨线
- 经典系统：捕食者-猎物、阻尼振子、**洛伦兹吸引子**（3D）

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **WebGL 上下文丢失** | 切换标签页、显卡驱动问题会导致上下文丢失。**必须处理 `webglcontextlost` 事件并恢复** |
| **Marching Cubes 分辨率不当** | 太粗漏细节，太细卡死。需要**自适应分辨率 + 上限保护** |
| **网格分辨率写死** | 不同函数需要不同分辨率。`sin(10x)` 与 `x+y` 需求差 100 倍 |
| **GPU 资源泄漏** | three.js 的 geometry/material 不 dispose 会累积泄漏。**必须有统一释放路径** |
| **3D 与 2D 状态不同步** | 若各自维护一份文档状态，撤销栈会彻底混乱。**共享单一状态源** |
| **在集显上直接崩** | 需检测 WebGL 能力并降级或提示 |
| **RK4 步长写死** | 刚性方程需要自适应步长。至少在文档中说明限制 |
| **过早引入 WASM** | 若 Marching Cubes 用 TS 能跑，就不要上 Rust/WASM。**先用满 TS 的额度** |
| **三个相机控制库混用** | 只用 three.js 的 OrbitControls，别自己再写一套 |

## 验收方式

```bash
pnpm test src/render3d src/math/ode
pnpm bench
pnpm dev
```

**人工确认项**：

1. 绘制 `z = sin(x)*cos(y)`，旋转一圈，观察帧率
2. 切平面拖动，检查偏导数数值
3. 洛伦兹吸引子，确认形状正确
4. 切换到 2D 视图再切回，确认状态未丢失
5. 长时间（5 分钟）旋转，用浏览器任务管理器确认内存稳定

## 依赖说明

本版需要 v0.2 的**符号求导支持多变量偏导**（切平面需要 `∂f/∂x`、`∂f/∂y`、`∂f/∂z`）。若 v0.2 只实现了单变量求导，需在本版扩展——这是对 v0.2 的一次增量增强，不构成重构。
