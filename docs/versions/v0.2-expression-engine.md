## 工作内容

### 1. 词法分析器（Lexer）

- 数字：整数、小数、科学计数法 `1e-3`
- 标识符：变量、函数名、常量
- 运算符：`+ - * / ^ % !`、比较符（为 v0.4 求根准备）
- 分隔符：`( ) [ ] , ;`
- **记录每个 token 的源码位置**（行、列、起止偏移）——错误定位的前提

### 2. 语法分析器（Parser）

递归下降实现，优先级从低到高：

| 优先级 | 运算 | 结合性 |
|---|---|---|
| 1 | `=` `<` `>`（用于方程与不等式） | 左 |
| 2 | `+` `-` | 左 |
| 3 | `*` `/` `%` | 左 |
| 4 | **隐式乘法** `2x`、`3sin(x)`、`(x+1)(x-1)` | 左 |
| 5 | 一元 `-` `+` | 右 |
| 6 | `^` 幂 | **右**（`2^3^2 = 2^(3^2)`） |
| 7 | 后缀 `!` 阶乘 | — |
| 8 | 函数调用、括号、原子 | — |

**隐式乘法是重点也是坑**：`2x` 是乘法，但 `x2` 应是标识符还是 `x*2`？需明确规则并写进文档。

### 3. AST 节点类型（本版的核心数据结构）

必须覆盖：

- `Number`、`Constant`（pi、e、φ 等）
- `Variable`（x、y、t、θ 及自定义参数）
- `UnaryOp`、`BinaryOp`
- `FunctionCall`（一元/多元）
- `Piecewise`（分段函数，含条件表达式）
- `Assignment`（`a = 3`，用于参数定义）

**设计要求**：AST 必须可**无损序列化**为 JSON 并能反序列化（撤销栈、分享链接、Notebook 保存都靠它）。

### 4. 求值器

| 类别 | 函数 |
|---|---|
| 三角 | `sin cos tan asin acos atan atan2` |
| 双曲 | `sinh cosh tanh asinh acosh atanh` |
| 指数对数 | `exp ln log log2 log10 sqrt cbrt pow` |
| 取整与符号 | `abs floor ceil round sign min max clamp` |
| 组合 | `factorial gcd lcm binomial mod` |
| 特殊 | `erf gamma`（v0.7 统计需要） |

**边界行为必须显式定义**（不是留给实现随手决定）：

| 输入 | 约定 | 理由 |
|---|---|---|
| `1/0` | `Infinity`（不抛异常） | 绘图需要它来画渐近线 |
| `0/0` | `NaN` | 绘图时该点断开 |
| `ln(-1)` | `NaN`（实数域） | 定义域外不绘制 |
| `sqrt(-1)` | `NaN` | 同 v0.9 再引入复数域 |
| `tan(pi/2)` | 有限大数而非 `Infinity` | 见下方陷阱说明 |
| `0^0` | `1` | 与主流计算器一致 |

### 5. 符号求导

对 AST 递归求导，返回**新的 AST**（不是数值）：

- 幂法则、乘积法则、商法则、链式法则
- 初等函数的导数表
- 结果**不做激进化简**（避免引入错误），但做基本整理：常数折叠、`1*f → f`、`f+0 → f`

> 求导结果在 v0.4 的切线动画中直接使用。

### 6. 错误报告

错误信息必须包含：**位置**（行:列）、**期望**、**实际**、**原文片段与指示符**。

```
错误：第 1 行第 5 列
  sin(x)) + 1
      ^
期望运算符或表达式结束，实际遇到 ')'
提示：括号可能多余
```

### 7. 参数系统

- 从 AST 中**自动识别自由变量**，区分自变量（x/t/θ）与参数（a/b/c）
- 每个参数有：默认值、最小值、最大值、步长
- **整个参数集合可序列化为 JSON**

## 验收标准

### 功能验收

- [ ] 以下表达式全部解析并求值正确：
  - `2x + 3`（隐式乘法）
  - `sin(x)^2 + cos(x)^2`（恒等于 1，误差 < 1e-12）
  - `x^2^3`（右结合，等于 `x^8`）
  - `-x^2`（一元负号优先级，等于 `-(x^2)`）
  - `2^3!`（后缀阶乘）
  - `{x < 0: -x, x >= 0: x}`（分段函数）
  - `log(x, 2)`（多元函数）
  - `1e-3 * x`
- [ ] 符号求导结果**数值可验证**：对 `f(x) = sin(x)*exp(-x^2)`，在 100 个随机点上比对 `f'(x)` 的符号求导结果与中心差分，相对误差 < 1e-6
- [ ] AST 序列化：任意表达式 → JSON → 反序列化 → 求值，结果与原 AST 完全一致
- [ ] 参数识别：`a*sin(b*x + c)` 自动识别出参数 `{a, b, c}`
- [ ] 错误信息包含准确的行列位置与指示符

### 质量验收

- [ ] **单表达式解析 + 求值 < 0.1 ms**（1000 次平均）
- [ ] AST 编译为可复用闭包后，**单点求值 < 100 ns**
- [ ] 单元测试覆盖：每个运算符、每个内置函数、每类错误、边界行为表全部条目
- [ ] 测试用例数 **≥ 150**
- [ ] 模糊测试：对随机生成的畸形输入不崩溃（只抛结构化错误）

### 文档验收

- [ ] `docs/expr-syntax.md` 完整描述语法、运算符优先级表、内置函数表、边界行为约定
- [ ] 文档中的每个例子都是可运行并已验证的

## 风险与陷阱

| 陷阱 | 说明 |
|---|---|
| **`tan(pi/2)` 的数值问题** | `pi/2` 是浮点数，`tan` 会算出约 1.6e16 而非 `Infinity`。绘图时这会画出一条几乎垂直的假线。**对策**：v0.3 的采样器必须检测"函数值突变"而不仅是"值为 Infinity" |
| **隐式乘法歧义** | `x2`、`2e`（是 2000 还是 `2*e`？）、`xy`（一个变量还是 `x*y`？）。**规则必须先定、写进文档、写进测试** |
| **`-x^2` 的优先级** | 数学约定是 `-(x^2)`，但很多解析器实现成 `(-x)^2`。必须按数学约定 |
| **忽略浮点误差累积** | 求导的数值验证要用相对误差而非绝对误差 |
| **AST 设计过早优化** | 不要现在就想"编译成字节码"。先保证正确与可序列化 |
| **错误信息敷衍** | 错误提示质量直接决定这个工具好不好用。**这一版就要做好**，后面不会有人回头补 |
