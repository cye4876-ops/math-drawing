# 数值算法说明（v0.4）

本文记录 `src/math/numeric/` 的算法选型、收敛条件与失败回退策略。全部算法有**明确的最大迭代/深度上限**，不存在死循环路径。

---

## 1. 求根 `findRoots`（`roots.ts`）

### 整体策略：扫描定界 + 括号内求根

```
可见范围 [xMin, xMax]
  └─ 自适应扫描（默认 2048 采样点；工具层按画布宽度 1024~8192）
       ├─ 采样值 == 0        → 精确零点
       ├─ 相邻两点变号        → 变号括号 → rtsafe
       ├─ 连续零区段          → 按两侧符号分类（异号=常规根 / 同号=repeated 重根）
       ├─ 局部极小 |f| < 触根容差 → 黄金分割细化 → 触根判定
       └─ 端点根检测
  └─ 按视窗宽度 1e-7 相对容差合并重复根
```

**选型理由**：纯牛顿法会漏根（需要好初值）且可能在平坦区发散；纯扫描精度不足。扫描负责"不漏"，括号内牛顿负责"求准"——这是教科书组合（Numerical Recipes 的 `rtsafe`）。

### rtsafe：安全牛顿（牛顿 + 二分回退）

- 每步先尝试牛顿更新 `x - f/df`；
- 若牛顿步**跑出当前括号**或步长不合理，退化为**保括号二分**（`x = (lo+hi)/2`）；
- 迭代上限 **120 次**（或区间缩到 `X_TOL = 1e-13` 以内）。

**导数接近 0 时**：牛顿步趋近 ±∞ → 自动落入二分分支；若符号导数不可用（`df === undefined`）则直接全程二分。两条路径均有单测覆盖（含 `x³−x` 在导数 0 点附近的回退）。

### 重根/触根（`x²` 在 0 处）

- 扫描到**零区段**：两侧同号且内部 |f| 极小 → 标记 `repeated`；
- 扫描到**触根**（未变号但 |f| 极小）：在 `[x-Δ, x+Δ]` 内做**黄金分割极小化** `|f|`，收敛后按符号分类；
- `touchTol` 与 `acceptTol` 由采样值的 90 分位数自动标定（`max(1e-12, p90·1e-5)` / `max(touchTol, p90·1e-8, 1e-12)`）。

**伪根拒绝**：跨极点函数（如 `tan`）在极点两侧变号，扫描会产生伪括号。细化后按 `|f(根)| ≤ acceptTol` 复核，超限即拒绝。

### 失败回退

| 情形 | 行为 |
|---|---|
| 导数不可用/牛顿步越界 | 二分（仍收敛，稍慢） |
| 括号内无符号变化（数值噪声） | 返回括号中点并做 acceptTol 复核 |
| 达到迭代上限 | 返回当前最优点（括号内必有根，误差 ≤ 区间宽） |
| 根数超过 2048 | 截断（保护表格渲染） |

### 交点 `findIntersections`

构造差函数 `d(x) = f₁(x) − f₂(x)`，并组合符号导数 `d′(x) = f₁′(x) − f₂′(x)`，直接复用上述管线。因此交点与零点共享全部收敛/回退保证。

## 2. 自适应 Simpson `adaptiveSimpson`（`integrate.ts`）

- **容差**：绝对误差 1e-10（可按调用覆盖）
- **最大深度**：20；**最大求值次数**：200 000（双保险）
- 每层用 Richardson 外推误差 `|I_left + I_right − I| / 15` 判断是否继续细分；
- **errorPeak 只累计"被接受叶子"**的 Richardson 项（避免把内部大估计当成最终误差）；
- 触顶时返回 `较优值 ± max(errorPeak, tolerance)` 并在结果中标记 `truncated`。

**选型理由**：被积函数来自表达式编译闭包，光滑但可能局部陡峭（如 `sin(1/x)`）；自适应 Simpson 对平滑段一两次细分即收敛，对陡峭段自动加密，实现简单、误差估计直观。与高斯-克朗罗德相比不依赖权重表，适合任意表达式。

**已知行为**：跨奇点（如 `1/x` 跨 0）时误差估计会显著变大或标记截断——本版**不尝试检测奇异积分**，读数中的误差估计即为提示。

## 3. 黎曼和 `riemannSum`（`riemann.ts`）

- 四模式：`left / right / mid / trapezoid`；
- `n` 限幅 1~10 000（工具层 UI 限 1~100）；
- 求和为单遍 O(n)，无持久状态。

**不做增量更新**：`n ≤ 100` 时每帧重算约 100 次编译闭包求值（单测含性能断言），远低于一帧预算（16 ms）；动画 1→100 全速推进时实测帧率不受影响。增量机制（缓存上一帧的部分和）只在 `n` 单调增加时成立，与"拖动滑杆回退/切换模式"语义冲突，复杂度不划算。

## 4. 屏幕空间最近点 `nearestPointOnPolylines`（`nearest.ts`）

- 输入：采样折线（可多段——多值曲线）、投影函数 `project`、目标屏幕点、最大距离；
- 对每条线段做**屏幕空间点到线段投影**，取全局最近，返回折线参数点与距离；
- `t` 字段透传（参数曲线/极坐标用于反查曲线参数并求导数分析）。

**为什么在屏幕空间求最近点**：吸附是**视觉行为**——用户判断"鼠标离画出来的线多近"用的是屏幕距离；在数学空间求距离在非等比视图（x/y 比例不同）下会偏。屏幕空间投影天然规避这个问题，且对圆/椭圆/极坐标曲线同样正确（单值函数"取同 x 点"的做法在多值曲线上失效）。

## 5. 收敛条件与上限一览

| 算法 | 收敛判据 | 迭代/深度上限 | 失败回退 |
|---|---|---|---|
| rtsafe 求根 | 区间宽 ≤ 1e-13 或 \|f\| ≤ acceptTol | 120 次迭代 | 二分步/截断保护 |
| 黄金分割触根细化 | 区间宽相对收敛 | 内部固定轮数 | 返回最优点 |
| 自适应 Simpson | Richardson 误差 ≤ 1e-10 | 深度 20 / 求值 20 万 | 标记 truncated |
| 黎曼和 | 不适用（直接求和） | n ≤ 10 000 | — |
| 最近点 | 不适用（有限折线扫描） | 折线段数 | 无命中返回 null |
