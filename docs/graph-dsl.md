# 图文本 DSL（v0.5）

用一行行文本描述图结构，与画布**双向同步**（文本改动 → 画布更新；画布编辑 → 文本回写）。

> 状态：解析器（`src/graph/dsl-parser.ts`）与双向同步 UI（图面板 DSL 编辑区，阶段 4）均已交付；同步策略与防循环机制见下文「与画布同步的约定」。

---

## 语法

| 形式 | 含义 | 示例 |
|---|---|---|
| `NAME` | 声明一个顶点（孤立点） | `A` |
| `NAME - NAME` | 无向边 | `A-B` |
| `NAME -- NAME` | 无向边（等价写法） | `A -- B` |
| `NAME -> NAME` | 有向边（A → B） | `C->A` |
| `NAME - NAME : 权重` | 带权边（无向/有向均可） | `A-B:3`、`C->A:2.5` |
| `# 注释` | 到行尾为止 | `A-B:3  # 主干道` |

- **语句分隔**：逗号 `,`、分号 `;`、换行均可混用；
- **名称规则**：字母、数字、下划线、汉字（不含 `-` `:` `,` `;` 与空白）；数字名如 `2->3` 合法；
- **权重**：数字（含小数、负数、科学计数）：`3`、`2.5`、`-1`、`1e3`；缺省为无权边；
- 端点在边语句中**自动声明**，无需单独列出；
- **自环与重边**：`A-A` 为自环；重复写 `A-B` 两次即两条平行边。

## 示例

规格示例（3 顶点 3 边，含一条有向边）：

```
A-B:3, B-C:2, C->A
```

稍大的例子：

```
# 三角带一条尾巴
甲-乙:1, 乙-丙:2, 丙-甲:1.5
丙 -> 丁
丁                  # 孤立点
```

## 错误处理（尽力解析）

单条语句出错**不会影响其余语句**：解析结果包含已成功解析的部分，以及逐条错误（`line` 行号、`column` 近似列号、中文消息）。

| 输入 | 结果 |
|---|---|
| `A-B:xx` | 该边跳过，报「权重无法解析」 |
| `->B` / `A-` / `@@@` | 该语句跳过，报「无法解析的语句」 |

解析器接口（`parseGraphDsl(text)`）返回 `{ nodes, edges, errors }`：
`nodes` 为首次出现顺序去重的顶点名列表；`edges` 含 `source/target/directed/weight`。

## 与画布同步的约定

- 文本 → 画布：解析成功后整体应用到图文档；**解析失败时画布保持上次有效状态**（不因输入中间态而清空图）；输入防抖 400ms，失焦时立即应用；
- 画布 → 文本：结构性编辑（增删顶点/边、改权重/方向）回写文本；**拖动节点只更新坐标、不回写**（坐标在 DSL 中不表达——位置由布局与拖动决定；结构等价时也不回写，避免打断输入）；
- **坐标继承**：文本重解析生成新图时，同名顶点保留原有坐标/颜色（`graphObjectFromDsl` 的第 4 参数），只有新顶点按环形布点；
- 同步采用**单向数据流 + 变更来源标记**，避免「A 改 B、B 又改 A」的循环更新：
  1. 用户聚焦编辑中 → 永不回写（输入优先）；
  2. 回写前用结构等价判断（labels 集合 + 边多重集比较）跳过「已一致」的情形；
  3. 图对象引用未变（视图/标记点等无关变化）→ 不回写。
