# 符号计算（v0.9）

「进阶」模式的符号子模块。**定位：有限规则集的符号引擎，不是完整 CAS（计算机代数系统）。** 本文档最重要的部分是「支持清单」与「不支持清单」——请先读边界，再读用法。

入口：工具条「进阶」→「符号」标签。输入表达式后点击操作按钮，结果以 KaTeX 排版显示在画布区（不等式附带数轴可视化）。

---

## 支持清单

| 操作 | 输入示例 | 输出 | 实现 |
|---|---|---|---|
| **化简** | `sin(x)^2 + cos(x)^2` | `1` | 常数折叠 + 恒等式重写（规则重写迭代 ≤20 轮 / 500 次改写） |
| **展开** | `(x+1)^3` | `x^3 + 3x^2 + 3x + 1` | AST → 系数数组 → 展开 |
| **解方程（多项式）** | `x^3 - 6x^2 + 11*x - 6 = 0` | `x = 1, 2, 3` | 有理根（BigInt 精确判定）+ 综合除法 |
| **解方程（复根）** | `x^2 + 1 = 0` | `x = i, -i` | 剩余二次因子判别式（含复根） |
| **解方程（高次 / 无有理解）** | `x^5 - x + 1 = 0` | 复数数值近似 | Durand-Kerner 迭代（残差校验后才返回） |
| **解方程（简单超越）** | `2^x = 8`、`ln(x) = 1` | `x = 3`、`x = e` | 模式匹配（$a^x = b$、$\ln u = c$） |
| **解方程（兜底）** | `sin(x) = 0.5` | `x ≈ 0.5236`（π/6） | 区间扫描变号 + 二分（[−50, 50]） |
| **解不等式** | `x^2 - 1 < 0` | `(-1, 1)` + 数轴 | 多项式实根分割 + 测试点判号；开闭端点区分；孤立点（如 $(x-1)^2 \le 0 \to \{1\}$） |
| **不定积分** | `x^2`、`x*sin(x)`、`1/(2*x+3)` | `x^3/3 + C` 等 | 多项式逐项 + 幂公式 + 初等函数表 + 线性换元 + 分部积分（有限子集） |
| **极限** | `sin(x)/x` @ 0、`(2x^3-x)/(x^3+4)` @ ∞ | `1`、`2` | 标准模式（sin u/u 等 5 类）+ 多项式比（精确）+ 数值 Richardson 兜底 |
| **LaTeX 输出** | 任意支持表达式 | 可被 KaTeX 渲染的 LaTeX | AST → LaTeX 递归映射 |

### 化简恒等式（完整列表）

常数折叠；`x+0`、`x*1`、`x-x`、`x/x`、`x^1`、`x^0`、`1^x`、`0*x`、`-(-x)`；`ln(e) → 1`；**`sin²u + cos²u → 1`**（加法项内两两配对，参数结构相等）；`x+x → 2x`。

### 积分规则（完整列表）

- 与积分变量无关的因子：$\int c\,dx = cx$；
- 多项式逐项幂公式（含 $(ax+b)^n$，$n \ne -1$）；
- $(ax+b)^{-1} \to \frac{1}{a}\ln|ax+b|$；
- $A^{ax+b} \to A^{ax+b}/(a\ln A)$（含 $e^{ax+b}$）；
- 线性内层换元：`sin cos tan ln exp sqrt atan asin`（各自表公式）；
- 有理二次分母：$\int \frac{c\,dx}{A + Bx^2}$（$B>0$ → atan 型；$B<0$ → 对数型）、$\int \frac{c\,dx}{\sqrt{A - x^2}}$ → asin 型；
- 分部积分：$(c_1x + c_0)\cdot\{\sin x, \cos x, e^x\}$ 三种表格公式。

## 不支持清单（重要）

**本引擎不会做的事**（做了会静默出错或明确报错）：

- ❌ **Risch 算法 / 任意函数的符号积分**——如 $\int e^{-x^2}dx$、$\int \frac{\sin x}{x}dx$ 会返回「无法积分」提示，而不是错误结果；
- ❌ **微分方程的符号解**（v0.8 的数值 ODE 求解是另一回事）；
- ❌ **级数展开到任意阶**（v0.4 泰勒展开针对具体函数做数值/系数展开）；
- ❌ **矩阵符号运算**；
- ❌ **三角方程的通解族**——`sin(x) = 0.5` 只给数值近似根，不给 $x = \frac{\pi}{6} + 2k\pi$ 形式；
- ❌ **不等式的一般情形**——仅多项式，且仅单变量；
- ❌ **分式/根式方程的化简与求解链**——如 $\sqrt{x} = x - 2$ 会走数值兜底；
- ❌ **多元符号运算**——化简/求解/积分/极限都针对单变量（默认 `x`）；
- ❌ **证明辅助**。

输入超出范围时，界面给出明确的中文提示（如「当前仅支持关于 x 的多项式不等式」「该函数在当前规则集内无法积分」），**不会给出错误结果或崩溃**。

## 与 nerdamer 的差分测试

规格要求：差分测试一致率 **≥ 95%**，不一致逐条记录。nerdamer（1.1.13，devDependency）**仅作测试参考**，不是运行时依赖。

### 方法

`src/symbolic/differential.test.ts`：确定性伪随机生成用例，对每个用例双方分别求值，在 7 个采样点上做**数值等价判定**（相对容差 1e-9）：

| 套件 | 用例数 | 对比方式 |
|---|---|---|
| 展开 | 30（10 固定 + 20 随机三因子积） | 我们 `astToPoly → polyToAst` vs `nerdamer expand`（其输出用我们的解析器解析） |
| 有理因式分解 | 30（固定例 + 随机整数根积） | `factorOverRationals` 重建式 vs `nerdamer factor` |
| 方程求解 | 15（整数根多项式） | `solveEquation` 实根集 vs `nerdamer solve` 根集（根排序后逐个比对，容差 1e-6） |

### 结果（v0.9 交付）

**75 / 75 = 100% 一致**（无任何用例触发 `console.warn` 记录）。断言门槛防回归：一致率 < 95% 时测试失败。

### 已知差异（表达形式，非数值）

1. **精确 vs 浮点**：nerdamer 用精确有理算术（如 $\sqrt{2}$ 保持 `sqrt(2)`、中间结果分数形式）；我们全程 IEEE 浮点，无理根以数值显示（`1.41421`）。数值上一致，形式上有别。
2. **因式顺序与常数提取**：如 `2*(-1+x)*(3+x)` vs 我们的排序输出——差分用数值采样，不受形式影响。
3. **nerdamer 已知边界 bug** 不需要迁就：差分测试的目的是「我们不错」，其输出解析失败或含复数时该用例跳过对照（计入不一致），当前无此情形。

## 实现架构

```
src/symbolic/
├── poly.ts         多项式引擎：系数数组、长除法、gcd、BigInt 有理根、
│                   二次公式复根、Durand-Kerner 数值全根、因数分解
├── simplify.ts     规则重写（含步数上限）+ 结构相等 + freeOf
├── solve.ts        方程求解入口（多项式 → 超越模式 → 数值兜底）+ 复数根格式化
├── inequality.ts   不等式求解 + 数轴区间数据
├── integrate.ts    有限规则集积分（步数上限 2 万）
├── limit.ts        标准模式 + 多项式比 + 数值 Richardson
├── latex.ts        AST → LaTeX
└── differential.test.ts   nerdamer 差分（devDependency）
```

### 数值格式化约定

- 近整数（容差 1e-9）→ 整数；
- 近分数（分母 ≤ 1024）→ `p/q`（如 `7/3`）；
- 其余 → 6 位有效数字；
- 复数 → `a + bi`、`-i`、`i`、`3i` 等人类可读形式。

## 性能与安全

| 保护 | 实现 |
|---|---|
| 化简不收敛 | 重写迭代 ≤ 20 轮、总改写次数 ≤ 500 |
| 积分规则爆炸 | 递归步数上限 20000，超限返回「无法积分」 |
| 求解卡死 | Durand-Kerner 迭代 ≤ 300 次 + 残差校验；数值扫描固定 4000 采样 |
| 1 秒返回（规格） | 常规表达式全部远低于（单测覆盖：80 层嵌套化简 < 1 s） |

## LaTeX 输出

AST → LaTeX 映射要点：分式 `\frac`、幂 `^{}`（复杂底自动 `\left(...\right)` 包裹）、根号 `\sqrt`、绝对值 `\left|...\right|`、函数名 `\sin \ln \Gamma` 等、比较符 `\le \ge \ne`、分段函数 `\begin{cases}`。

**渲染验证**：测试用 KaTeX（`throwOnError: true`）渲染全部输出样例（含 `(-2)^x`、`x!`、`floor/ceil`、`tanh/atan/asin` 等 17 例），并断言关键结构字符串（如 `x^2/2 → \frac{x^{2}}{2}`）。KaTeX 为运行时依赖（面板显示与测试共用）。
