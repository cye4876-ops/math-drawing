# 网页评审与改版方案（执行记录）

## 评审结论（四阶段）

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1 先修布局 | ① 工具栏层级混乱（模式 / 分析 / 坐标 / 文件操作混排换行）→ 拆分全局导航、当前模式工具、文件操作；② 窄屏画布被挤压 → 画布在上、编辑区在下；③ 侧栏无法有效收起 → 加收起按钮 | ✅ v2.4 完成 |
| 2 整理功能入口 | ④ 首屏缺引导 → 三个入口（画一个函数 / 探索参数变化 / 打开示例项目）；⑤ 空区域提前展开（图论无图时性质 / 矩阵 / 算法面板仍显示）→ 先突出创建入口；⑥ 三维任务混杂 → 分为对象、视图、分析，导出统一归口 | ✅ v2.4 完成 |
| 3 统一视觉 | 浅色优先 + 深色并存、主色蓝、字号 14–16px、网格主次分明、曲线多通道辨识 | ✅ v2.5 完成 |
| 4 完善体验 | 示例项目、输入反馈、快捷键提示、保存状态、课堂演示模式 | ✅ v2.5 完成 |

## 推荐布局（方案要点，v2.4 落地情况）

- 左侧编辑区宽度 280–320px，可整体收起（✅ 收起按钮 + localStorage 持久化）；
- 操作顺序固定：选择示例或输入函数 → 查看图像 → 选中曲线 → 分析 → 查看结果 → 导出（✅ 首屏引导按此顺序给出入口）；
- 窄窗口画布优先，编辑面板移到底部（✅ ≤ 920px 纵向堆叠）。

## 后续阶段实施建议

- **阶段 3（视觉统一）**：✅ v2.5 —— 浅色优先主题（浅灰页面 + 白色面板/画布 + 主色蓝）与深色一键切换（持久化、首帧预应用），网格主次/坐标轴/图论节点配色随主题；曲线 10 色调色板 + 名称/线型共同辨识；字号上调（曲线面板 13→14px）。3D 视口与专题画布保留专用深色风格；
- **阶段 4（体验完善）**：✅ v2.5 —— 示例项目画廊（10 示例一键应用）、输入实时反馈（✓/✗ + 参数提示）、快捷键提示对话框、保存状态指示（已保存/未保存修改）、课堂演示模式工具栏入口（Esc 退出）；
- **附图修订（v2.5 顺带）**：曲线参数滑块（a/b/c 自动识别，拖动预览/松手撤销，接入渲染·导出·保存·分享）——“探索参数变化”入口现在真正可调参数。
- **界面骨架重做（v2.6）**：评审后另出三稿可视化预览（`design/mockup-a-modern.html` 现代极简 / `design/mockup-b-classroom.html` 课堂大字 / `design/mockup-c-floating.html` 画布优先，`design/compare.html` 并列对比），经用户对比后**选定 C 方向并落地**：全幅画布 + 左侧浮动玻璃卡片 + 顶部玻璃栏 + 底部工具坞 + 状态胶囊；字体与图标采用开源资产 Inter（OFL）与 Lucide（ISC），预览稿与提取脚本保留在 `design/` 供后续参考。
