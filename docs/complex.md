# 复变函数可视化（v0.9）

「进阶」模式的复变子模块：定义域着色、Möbius 变换、分支示意（黎曼面）与围道积分。

入口：工具条「进阶」→「复变」标签（`?mode=advanced` 直达）。

---

## 定义域着色（Domain Coloring）

### 原理

把复函数 $f(z)$ 的相位与模长分别映射到颜色的二维属性：

| 维度 | 映射 | 含义 |
|---|---|---|
| 相位 $\arg w$ | 色相（色轮一圈 = $2\pi$） | 同一色相 = 同一辐角方向 |
| 模长 $\lvert w \rvert$ | 明度条纹（$|w|$ 每倍频一个周期） | 黑白环 = 等模线 |
| $\lvert w\rvert \to 0$ | **黑色** | 零点 |
| $f$ 未定义 / 非有限 | **白色** | 极点 |

外行直觉的约定（零点黑、极点白）与数学文献的常见变体不同，选择前者是为了「一眼可辨」。

网格线叠加（默认开启）：

- **等相位线**：每 $15°$ 一条（$\lvert\sin 12\varphi\rvert < 0.09$ 的暗化带）；
- **等模线**：$|w|$ 的每个倍频处一条（暗化带）。

两网格配合后，零点的「色轮汇聚」、极点的「色轮发散」与分支割线的相位跳变都清晰可见。

### 支持表达式

输入语法为单变量复数表达式（变量 `z`，虚数单位 `i`）：

- 基本运算：`+ − * / ^`（非负整数幂走快速路径）、括号、一元负号；
- 常数与函数：`pi`、`e`、`exp`、`log`（主值）、`sqrt`（主值）、`sin` `cos` `tan`、`sinh` `cosh` `tanh`、`gamma`（Lanczos 近似 + 反射公式）、`zeta`（Euler 变换 + 函数方程）、`abs`、`arg`；
- 阶乘：`factorial(z)`（= $\Gamma(z+1)$）。

示例：`(z-1)/(z+1)`（默认）、`sin(z)`、`z^3 - 1`、`gamma(z)`、`zeta(z)`。

### 控件

| 控件 | 范围 | 说明 |
|---|---|---|
| `f(z)` | 文本 | 表达式；解析错误在画布上方红条提示 |
| 色图 | standard / highcontrast | 高对比色图适合投影展示 |
| 视野 | 1 ~ 20 | 复平面视窗宽度（单位）；滚轮缩放、**拖拽平移**、双击重置 |
| 分辨率 | 256 / 512 / 1024 | 渲染像素尺寸上限；拖动中自动降到 ≤256 保证流畅 |
| 网格线 | 开关 | 等相位线 + 等模线 |

### 性能

规格验收：**1024×1024 < 100 ms**，实测达成（best-of 采样约 60–90 ms，视 CPU）。达成手段：

- 色相 → 2048 项 RGB 查找表（`hsvToRgb(h,1,v) = v × 查表值`，逐通道线性）；
- $\log_2 |w| = \tfrac12 \log_2(|w|^2)$，省一次开方；有限性检查内联；
- $\lvert\sin(\pi \log_2|w|)\rvert$ 与 $\lvert\sin 12\varphi\rvert$ 用 4096 / 3072 项查表；
- 采样步长预乘（`start + x*step` 取代每像素除法）。

⚠️ **`gamma(z)` / `zeta(z)` 每次求值约 1–10 μs**，1024 分辨率需数秒——面板会自动受分辨率上限保护，建议此类函数用 256 分辨率。这是规格认可的取舍（文档明示，不做 Worker）。

## Möbius 变换

分式线性变换 $f(z) = \dfrac{az+b}{cz+d}$。演示要点：

- **保角性**：正交网格的像在对应点仍正交（画布上直观可见）；
- **圆 → 圆**：橙色曲线为单位圆 $|z|=1$ 的像；
- 预设：恒等、反演 $1/z$、Cayley 映射 $(z-1)/(z+1)$、旋转 $e^{i\pi/4} z$；
- 「范围」滑块调整 z 平面可视区间；输出平面自动留边。

跑远的像点自动断开（分段折线），极点附近不会出现「大跨度直线」。

## 分支示意（黎曼面）

规格允许「多层/示意」而非严格 3D 几何。实现方式为**分支函数 + 域着色**：

- `sqrt(z)`：2 个分支（$\pm\sqrt{z}$）；主值分支在负实轴显示相位跳变（分支割线）；
- `log(z)`：3 层示意（$\ln z + 2\pi k i$，$k = 0,1,2$）。

选择分支后单独渲染该分支的域着色，面板标注分支说明文字。

## 围道积分

沿圆心在原点的圆做复围道积分：

$$\oint_{|z|=r} f(z)\,dz \approx \sum_k f(z_k)\, i r e^{it_k}\, \Delta t$$

圆参数化 $z(t) = r e^{it}$，梯形法 2000 采样点。结果栏显示数值、模与相位。

验证性演示（留数定理）：`1/(z-i)` 在半径 2 的圆上 ∮ ≈ $2\pi i$；半径 0.5 时（不含极点）≈ 0。

## 已知限制

- 黎曼面为**分层示意**，非严格 3D 曲面（规格明确此取舍）；
- `zeta` 采用 Euler 变换（|·| 收敛区）+ 函数方程（其余区域），临界线零点可辨（测试断言 $\lvert\zeta(0.5 + 14.134725 i)\rvert < 0.1$），但非工业级精度；
- Möbius 未做「动画插值」（拖参数连续变形），交互方式为预设切换 + 范围滑块；
- 谱系缩放上限 20，平移范围 ±50。
