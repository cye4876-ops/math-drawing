# 交互分析工具（v0.4）

v0.4 引入 7 个**分析工具**：追踪游标、切线、零点、交点、定积分、黎曼和、泰勒展开。工具是"查看"行为——只读文档，**不写入撤销栈**。

---

## 通用操作

| 操作 | 说明 |
|---|---|
| 激活工具 | 点击工具条上的工具按钮（同一时刻只有一个主工具激活） |
| 切换工具 | 直接点另一个工具按钮；旧工具的内部状态会先被完整清理 |
| 退出工具 | 再点一次当前工具按钮，或按 **Esc**，回到"选择/平移"模式 |
| 读数面板 | 激活工具后显示在**右侧栏**（曲线列表下方，不遮挡画布）；包含读数与控件（输入框 / 快捷符号 / 滑杆 / 按钮） |
| 空格键 | 黎曼和、泰勒：播放 / 暂停动画 |
| 缩放/平移 | 滚轮缩放（以光标为锚点）、空白处拖动平移；在面板/控件上的滚轮不会缩放视图 |

**读数中的数字格式**：6 位有效数字；极小/极大值用科学计数法；`—` 表示不可用。方程目前为纯文本（KaTeX 排版在 v0.6）。

**吸附行为**：追踪/切线把光标吸附到**屏幕距离最近的曲线点**（而非同 x 坐标取点），因此在多值曲线（圆、参数方程、极坐标闭合曲线）上同样正确。

## 1. 追踪游标

在曲线上滑动鼠标，实时显示：

- 当前点 `(x, y)`
- 一阶导 `f′(x)`（符号求导，非数值差分）
- 二阶导 `f″(x)`
- **曲率半径 ρ**（虚拟蓝色虚线圆为曲率圆/内切圆；ρ 越大曲线越平）

| 项目 | 值 |
|---|---|
| 吸附距离 | 60 px |
| 参数方程/极坐标 | 显示 `dy/dx`、`d²y/dx²`（由链式法则换算） |
| 隐函数 | 由梯度给出斜率；无二阶导与曲率圆（读数中标注） |

## 2. 切线

两种定位方式（等效）：

- 在曲线上按下即设置切点，拖动切点切线随之滚动；
- 在读数面板的「切点 x₀」输入框直接输入 x 坐标，回车即在 `(x₀, f(x₀))` 生成切线（支持数字与常量表达式，如 `1.5`、`pi/2`；目前仅显函数）。

显示切点坐标、斜率 `k` 与**切线方程**（点斜式，`x = x₀` 表示竖直切线）。

**精确显示（v2.8.1）**：当 x₀ 为手工输入的精确值（数字/常量/根式，如 `0`、`pi/2`、`sqrt(2)`）且函数与其导数在该点可精确求值时，切点、斜率与方程均给**精确式**——如 `sin(x)` 在 `π/2` 处显示切点 `(π/2, 1)`、斜率 `0`、方程 `y = 1`；否则回退数值（拖动切点始终为数值）。

| 项目 | 值 |
|---|---|
| 吸附距离 | 72 px |
| 方程示例 | `y = 0.536911·x + 0.302853`；精确：`y = 1`、`y = −(x − π)` |
| 快捷符号 | 输入框下的 `0`、`π/2`、`π`、`2π`、`-π`、`e` 按钮：点击即作为输入值生效 |
| 输入错误反馈 | 面板提示“无法解析 / 不在定义域 / 没有可用曲线”，并保留上次有效切点 |

## 3. 零点

自动在**当前可见范围**内找出所有显函数曲线的零点：

- 红点 = 常规零点（两侧变号）
- 橙点 = 重根/触根（无符号变化，如 `x²` 的 0）

| 项目 | 值 |
|---|---|
| 扫描分辨率 | 按画布宽度自适应（1024~8192 采样点） |
| 显示上限 | 每曲线最多列出 12 个（超出标注总数） |
| 自动重算 | 激活期间文档变化（增删/编辑曲线、改视图不必要）自动重算 |

> 限制：非常密集的根（相邻根间距小于扫描步长）可能漏检；重根判定基于"两侧同号 + 极小 |f|"，接近机器精度的浅触根可能被归为常规根。

## 4. 交点

对**显函数两两求交**（如 `sin(x)` 与 `x³−x`），在可见范围内列出全部交点坐标。

| 项目 | 值 |
|---|---|
| 支持范围 | 显函数 × 显函数（本版不支持隐函数/参数方程求交） |
| 显示上限 | 每组曲线对最多列出 8 个（超出标注总数） |
| 原理 | 构造差函数 `d(x) = f₁(x) − f₂(x)`，复用零点求解管线 |

## 5. 定积分（v2.8：解析解优先）

拖拽区间端点（蓝色手柄）选择 `[a, b]`，或用面板的**下限 a / 上限 b 输入框**直接设置（支持数字与常量表达式：`0`、`pi`、`pi/2`、`2*pi`、`-pi`、`e`、`sqrt(2)`……，也可以点输入框下的快捷符号一键填入）。区间内曲线与 x 轴之间填充阴影。

显示：

- **两端点均为手工输入的精确文本时**：先求符号原函数 F（有限规则集），端点用精确值引擎求值（π/e/根式保持符号），给出**精确结果**（如 `∫₀^π sin x dx = 2`、`∫₀^π x dx = π²/2`、`∫₀^2 √x dx = 4√2/3`），并同时用自适应 Simpson 独立数值校验（不一致则拒绝解析值并回退，防符号积分实现缺陷）；面板同时显示原函数 F(x) 文本；
- 其余情况（拖动端点 / 无解析原函数 / 端点为非精确值）：回退**自适应 Simpson**（容限 1e-10）并显示误差估计与求值次数。

| 项目 | 值 |
|---|---|
| 端点吸附 | 距端点 12 px 内可抓取；基线（y=0）附近 ±20 px 内才响应 |
| 初始区间 | 默认取可见范围 25%~75% |
| 输入错误反馈 | 面板提示“无法解析”，并保留上次有效区间 |
| 精确结果展示 | `2`、`π²/2`、`4√2/3`、`e − 1`、`2 ln 2` 等（分子分母/根式/π 保持符号） |

> 限制：不支持奇异积分（如 ∫dx/x 跨 0）；符号积分仅覆盖有限规则集（超出时回退数值并标注原因）。

## 6. 围成面积（v2.8）

选择两条可见显函数曲线（面板「曲线 A / 曲线 B」按钮组），在 `[a, b]` 上计算两曲线**围成的面积**：

- 区间内自动数值求交点（采样 + 二分细化）并按交点分段，逐段计算 `∫|f − g|`；
- **交点与端点吸附**：接近简单有理数（`1/2`）或 π 的有理倍（`π/4`）时还原为精确值，逐段符号积分——常见情形直接给出精确总面积（如 `y = x` 与 `y = x²` 在 `[0, 1]` 上为 `1/6`，`sin x` 与 `cos x` 在 `[0, π/2]` 上为 `2√2 − 2`）；
- 面板逐段列出区间与面积、区间内交点、总面积（精确或 `≈` 数值）；画布上两曲线之间填充阴影、交点处标点；
- 无法精确（交点无简单表示 / 超出符号积分规则集）时整条总面积回退数值并标注。

## 7. 黎曼和

四种模式：**左端点 / 右端点 / 中点 / 梯形**。`n` 可从 1 动画过渡到 100：

- 播放（≈2 秒 1→100） / 单步 / 重置按钮，或空格键播放暂停
- 拖动 `n` 滑杆直接定位；实时显示近似值、参考值（Simpson 数值解）与误差

**性能与实现说明**：不做"增量更新"优化——`n ≤ 100` 时每帧重算一次求和仅约 100 次编译闭包求值（实测 < 0.05 ms/帧，远低于 16 ms 帧预算），增量机制会引入状态复杂度而收益为零。

## 8. 泰勒展开

两种设置展开点的方式：**点击画布**，或在面板「展开点 x₀」输入框输入坐标（支持 `pi/2` 等常量表达式；下方快捷符号点击即用）。逐阶叠加泰勒多项式并显示展开式文本：

- 阶数 1~15（滑杆、单步、播放动画每 800 ms 升一阶）
- 显示"可视范围最大偏差"帮助判断逼近质量
- 零系数项自动省略（如 `sin(x)` 在 `x₀=0` 展开时偶次项为 0）
- **精确显示（v2.8.1）**：手工输入精确展开点（如 `pi/2`）且函数在精确规则集内时，展开点与系数给精确式（如 `sin(x)` 在 `π/2` 处：`T3(x) = 1 − 1/2·(x−π/2)^2`）；点击/拖动展开点或超出规则集时回退数值

> 限制：远离展开点的发散行为是数学事实（多项式不会在全局逼近）；本版不显示余项形式；逼近曲线仍以数值系数绘制（精确式仅用于读数展示）。

## 9. 图编辑（v0.5）

> 双模式界面：工具条**左上角**可切换「函数绘图」与「图论绘图」。**两模式的内容与坐标视图完全独立**（函数曲线与图对象互不可见、缩放平移各自保存）；图论模式隐藏坐标轴/网格与坐标相关控件；URL `?mode=graph` 可直接进入（存在 `?graph=` 参数时自动进入图论模式）。

在画布上直接编辑图（顶点/边）。工具面板提供三个模式：

| 模式 | 操作 |
|---|---|
| **移动**（默认） | **点击空白建点**（文档无图时自动建立；标签自动取 A、B、C…）；**拖动节点移动**（实时跟手）；**右键删除**命中的节点或边 |
| **连边** | 从节点按下拖到另一节点松手建边；面板可切换「无向 / 有向」；拖动过程显示虚线预览 |
| **删除** | 点击节点删除（**连同其关联边**）；点击边删除单条 |

- 所有图编辑操作均**进入撤销历史**（拖动为一步）；右键在任意模式下都可删除命中元素；
- 拖动采用「预览 + 追认」机制：过程实时渲染但不产生历史噪音，松手时合并为单步撤销；
- 命中半径 14px（节点圆或边路径）；曲线不参与图工具删除（曲线删除在右侧曲线列表）；
- 建点坐标即点击处的数学坐标，节点尺寸为屏幕恒定（缩放不变）。

**画布点击选中编辑**：移动模式下**单击节点**或**单击边**（不拖动）即在图面板顶部打开「选中元素」卡片——

- 节点：查看标签与关联边数，可**删除节点（连同关联边）**或取消选择；
- 边：查看两端标签（有向显示 →），可直接**输入权重**（回车/失焦提交，清空 = 取消权重）、
  **清除权重**、**删除边**或取消选择；
- 选中元素在画布上**琥珀高亮**；点击画布空白、删除元素或结构变化时卡片自动关闭。

### 图面板（图论模式侧栏）

| 区块 | 功能 |
|---|---|
| **选中元素** | 画布单击节点/边后出现在顶部：删除节点（连同关联边）/ 删除边 / 边赋权与清除权重 / 取消选择（见上文「画布点击选中编辑」） |
| **图族** | **14 种**预置图族（完全图、二分图、环、路、二叉树、Petersen、超立方体、网格、**星图、轮图、梯子图、棱柱图、风车图、八面体**）选择 + 参数 + 「生成」（替换当前图内容，可撤销）；**参数越界/非法组合时禁用生成并提示**（如超立方体 k ≤ 6、网格顶点 ≤ 200、二分图边数 ≤ 400） |
| **DSL** | 文本编辑区与画布**双向同步**：输入防抖 400ms 自动应用；解析错误显示行号且**不改画布**；画布/工具/撤销引起结构变化时回写文本 |
| **布局** | 「环形」「网格」「分层」（即时）与「力导向」（**WebWorker 内运行 FA2**，不阻塞主线程；200 节点/500 边实测 < 1s） |
| **矩阵与谱** | 邻接 / 拉普拉斯矩阵（**点击格子 ↔ 画布高亮联动**）、特征值（对称阵全谱，按重数聚合）、**有向图复数全谱**（特征值 chips + 复平面散点，谱半径虚线圆，顶点 ≤ 40）、谱半径与 Perron 向量；拉普拉斯视图另显示 **L 的谱**（**0 重数 = 连通分量数**、**λ₂ 代数连通度**）；**Floyd 单步播放时矩阵行列随中间点高亮** |
| **算法** | 16 个算法（BFS/DFS/Dijkstra/Bellman-Ford/Floyd/拓扑/Prim/Kruskal/贪心·DSATUR 着色/二分/强连通/**割点与桥**/**欧拉路**/匹配/最大流）**单步 / 播放（可调速）/ 回退 / 到末尾 / 重置**；当前步骤琥珀高亮、**已走过的边/节点以玫红累积标记（逐步长出遍历树/最短路树/生成树，回退自动收缩）**；**着色结果直接上画布**；结果摘要（距离表/路径/矩阵/拓扑序/色块/总权重/流量表/割点与桥清单/欧拉路序列/错误） |
| **统计** | 顶点/边计数、删除此图 |
| **图的性质** | 连通性 / 二分性 / 欧拉路；平面性（“禁图”检测与禁用子图证据高亮）；**二分化 b(G)**：最少删几条边可得二部图，可高亮需删除的边；**色数 χ(G)** / **最小点覆盖 τ(G)**（可高亮）/ **生成树计数**（Kirchhoff，分离图 0，超大计数科学计数） |

同步与回写细节（防循环、坐标继承）见 [graph-dsl.md](graph-dsl.md)。

## 10. 导出与分享（v0.6）

工具条「导出…」打开导出面板（详见 [export.md](export.md)）：

| 标签页 | 功能 |
|---|---|

- 图性质面板新增**色数 χ(G)**（顶点 ≤ 24 精确，更大给贪心上下界）与**最小点覆盖 τ(G)**
  （顶点 ≤ 40 精确分支，更大 2-近似），可一键在画布高亮最小点覆盖（琥珀）。

## 11. 统计与数据（v0.7）

工具条第三个模式标签「统计与数据」（或 URL `?mode=stats`）。数据以独立图层存在，可撤回、可分享、可导出 PNG。

| 区域 | 说明 |
|---|---|
| **导入数据** | 粘贴 CSV/TSV（自动分隔符/表头/缺失值）、文件导入、`y = f(x) + noise` 表达式生成 |
| **数据表** | 前 40 行预览（缺失值以 `—` 显示） |
| **图表** | 四选一：散点+回归 / 直方图+KDE / 分布曲线 / 模拟动画 |
| **描述统计** | 选列显示均值~峰度与 SVG 箱线图 |

**散点+回归**：x/y 列可选；6 类回归（线性/多项式 1~8 阶/指数/对数/幂/自定义 LM）；显示 n、Pearson r、Spearman ρ、方程、R²、调整 R²、残差标准误；「残差图」勾选后主图与残差条带联动。

**分布曲线**：10 种分布参数滑块（拖动 preview、松手一步撤销）；画布上拖动「统计探针」设置 x，琥珀区域 = P(X ≤ x)；可叠加第二分布对比。

**模拟动画**：LLN / CLT / 蒙特卡洛求 π / Bootstrap / 随机游走；播放/暂停/重置（重置 = 新种子）。

**统计探针工具**（工具条）：分布图拖动设探针；散点图点击选点（再点取消，点空白清空）。点选不写入撤销历史。

细节（CSV 容错规则、QR 选型理由、性能边界）见 [statistics.md](statistics.md)。

## 12. 3D 与场（v0.8）

工具条第四个模式标签「3D 与场」（或 URL `?mode=space`）。WebGL（three.js）渲染与 2D 画布并存，**共享文档与撤销栈**（可在 3D 与 2D 间自由切换）。

| 区域 | 说明 |
|---|---|
| **添加** | 预设：曲面（sin·cos/马鞍/抛物/平面/圆锥/隐式球/双曲面/椭球/环面/莫比乌斯/旋转体/正多面体与棱柱棱锥）、空间曲线（洛伦兹/螺旋/直线/环面纽结）、向量场（旋转/径向/鞍点/谐振子相图/捕食者-猎物）、ODE 解（5 例） |
| **对象** | 列表（可见开关 / 选择 / 删除）；参数按类型编辑（表达式、范围、分辨率、透明度、颜色、场密度与长度、流线种子、ODE 初值与步数）；**参数化预设**（平面/椭球 a·b·c、环面 R/r、洛伦兹 σ/ρ/β、捕食者-猎物系数…）在「参数」区顶部显示**系数滑块**，拖动实时重算表达式 |
| **视图** | 相机（透视/正交）、着色（单色/高度×色图/法向）、色图（viridis/plasma/coolwarm/gray）、等高线层数（0~12）、切平面开关与读数、重置视角 |
| **导出** | 截图 PNG / 旋转 GIF（绕 z 轴一圈；**帧数与播放速度可调**，导出期间遮罩提示、完成后恢复视角） |

**交互**：左键旋转、右键平移、滚轮缩放；切平面开启时在曲面上左键拖动移动切点（空白处仍为旋转）。

**切平面读数**：切点 f(x₀,y₀)、∂f/∂x、∂f/∂y（**符号求导**结果，非数值差分）。

细节（MC 取舍、LOD、WebGL 兼容性与降级、导出）见 [3d.md](3d.md)。

## 已知限制汇总

| 限制 | 说明 |
|---|---|
| 求交 | 仅显函数两两求交 |
| 零点/交点扫描 | 扫描分辨率有限，极密集的根可能漏检（读数中有提示） |
| 重根 | 检测基于数值扫描 + 黄金分割细化；接近机器精度的浅触根可能误分类 |
| 定积分 | 精确解析解仅在“两端点为手工输入的精确文本”且函数在有限规则集内时给出；其余回退自适应 Simpson；不支持奇异积分（跨奇点拒绝解析值） |
| 围成面积 | 交点数值求解后吸附简单值；无简单交点的段落回退数值（总面积标注 ≈） |
| 切线/泰勒 | 精确式仅在“手工输入精确坐标”且函数（及其导数）在精确规则集内时给出；拖动定位与超出规则集回退数值 |
| 隐函数 | 追踪游标可用（梯度斜率）；无二导/曲率；不参与求交与积分 |
| 泰勒 | 仅显函数；不显示余项 |
| 对数坐标 | 视图中心与轴位置自动归一化为正数（切换到对数时若原值为非正会置 1）；切线/泰勒曲线在 `y ≤ 0` 区域无定义，自动断开不绘制 |
| 动画 | 依赖浏览器 rAF；页面不可见（后台标签）时暂停（浏览器行为） |
| 二分化 b(G) | 顶点数 ≤ 20 时精确枚举（首次计算约百毫秒级）；更大图用贪心近似并在面板标注「近似」 |
| 拉普拉斯谱 | 仅对称图（无向）给出；有向图仍可看邻接矩阵与谱半径 |
| 色数 / 点覆盖 | χ：顶点 ≤ 24 精确（DSATUR 回溯），更大给贪心上下界；τ：顶点 ≤ 40 精确（分支+匹配下界），更大 2-近似 |
| 割点/桥与欧拉路 | 无向语义（有向边按无向处理）：割点/桥用 Tarjan（平行边不舏桥）；欧拉路要求 0/2 个奇度顶点且含边部分连通 |
| 有向图复数全谱 | 顶点 ≤ 40 时用特征多项式（Faddeev–LeVerrier）+ Durand–Kerner 数值求根（精度约 1e-8，可视化用途）；过大仅给谱半径 |
| 3D 模式 | 需 WebGL（无则提示且不影响其他模式）；隐式曲面 ≤ 128³；固定步长 ODE（刚性方程受限）；点/向量独立图元未实现 |
| 生成树计数 | 顶点 ≤ 64 全谱计算（Kirchhoff）；更大跳过；计数超 2^53 时以科学计数展示 |
| SVG/TikZ 网格 | 仅直角坐标导出网格；极坐标/对数坐标系只导出曲线 |
| 动画导出 | 三类帧源（图算法/黎曼和/泰勒）；帧数由 n 上限/阶数/算法步骤数决定 |
| 统计导出 | 统计图当前仅支持 PNG（SVG/TikZ 面向曲线与图）；分布参数输入框暂无（仅滑块） |
| 统计表格 | 数据表为只读预览（前 40 行）；手工增删行列未实现，用粘贴/文件/生成替代 |
| 指数/对数/幂回归 | 需过滤定义域（y>0 或 x>0），过滤行数在面板提示 |

## 架构说明（开发者）

- 工具实现 `Tool` 接口（`src/tools/tool-registry.ts`）：`activate/deactivate/onPointerXxx/onKeyDown/drawOverlay/getReadout/getControls/onControl/isAnimating`
- **单激活不变量**：`ToolRegistry.activate` 保证先 `deactivate` 旧工具；事件经 `interactions.ts` 的 `toolHooks` 转发（工具不自行注册 DOM 监听）
- 工具只通过 `ToolContext`（store/getView/getSize/requestRender/notify）与外界通信；`notify` 驱动读数面板刷新
- 动画：`isAnimating()` 返回 true 时 App 在绘制回调尾部继续请求下一帧
- 数值算法细节见 [docs/numeric-methods.md](numeric-methods.md)
