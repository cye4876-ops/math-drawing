# 统计与数据（v0.7）

v0.7 引入**第三个界面模式「统计与数据」**：导入/生成数据 → 可视化（散点+回归 / 直方图+KDE / 分布曲线 / 模拟动画）→ 描述统计。数据以独立图层（`dataset` 对象）存在于文档中，不触碰曲线与图论核心。

---

## 1. 数据导入

| 方式 | 说明 |
|---|---|
| **粘贴 CSV/TSV** | 面板顶部文本框粘贴任意表格，点击「解析粘贴内容」（> 4000 行自动分片，不阻塞 UI） |
| **导入文件…** | 选择 .csv / .tsv / .txt 文件 |
| **从函数生成** | `y = f(x) + noise`：输入表达式（完整表达式引擎语法）、点数 n、x 范围、噪声 σ |

### CSV 容错规则

| 情况 | 处理 |
|---|---|
| 分隔符 | 自动识别**逗号 / 制表符 / 分号**（取样本行中列数最稳定者） |
| 引号 | `"..."` 内的分隔符不算切分；`""` 表示转义引号 |
| BOM / CRLF | 自动剥离 BOM；兼容 `\r\n` 与 `\n` |
| 表头 | 首行全非数字 → 视为表头；否则自动命名 `列1、列2…` |
| 缺失值 | 空串、`NA`、`NaN`、`-`、`—` → 该格为缺失（统计时被跳过，不视为 0） |
| 千分位 | `1,234.5`（引号包裹）与 `1.234,5`（欧洲小数逗号）两种千分位碎片自动合并 |
| 文本列 | 某列非数字占比 ≥ 50% → 整列置为缺失并在状态栏提示 |
| 行宽不齐 | 短行补缺失、长行截断 |

导入成功后面板显示「已导入 n 行 × m 列」，并可在「数据表」区预览前 40 行。

## 2. 散点图与回归

- **x 列 / y 列**任选，含缺失值的行成对丢弃；
- 显示 **n、Pearson r、Spearman ρ**、拟合方程、**R²、调整 R²、残差标准误**；
- **残差模式**：勾选后主图压缩到上 2/3，下方为残差条带（x 对齐），离群残差一眼可见；
- 点击数据点可选中（琥珀圈高亮，与残差条带联动）；点选不入撤销历史。

### 六类回归

| 类型 | 模型 | 方法 |
|---|---|---|
| 线性 | `y = a + bx` | 最小二乘（**QR 分解**） |
| 多项式 | `y = c₀ + c₁x + …`（1~8 阶） | 最小二乘（QR） |
| 指数 | `y = a·e^{bx}` | 对数线性化（需 y > 0，过滤计数提示） |
| 对数 | `y = a + b·ln x` | 线性化（需 x > 0） |
| 幂 | `y = a·x^b` | 双对数线性化（需 x > 0, y > 0） |
| 自定义 | `a*exp(b*x)+c` 等（参数 `a`~`d`、`f`、`w`、`z`，≤ 4 个） | Levenberg–Marquardt（数值雅可比 + 阻尼正规方程） |

### 为什么用 QR 而不是正规方程

正规方程 $\beta = (X^TX)^{-1}X^Ty$ 把条件数平方：设计矩阵本身病态（如高质量多项式、x 尺度差异大）时，法方程的数值误差会被放大到不可用。本实现用**修正 Gram–Schmidt 的 QR 分解**求最小二乘解，条件数只受一次影响；单测中含病态数据的对照（闭式解误差 < 1e-10）。非线性回归才使用迭代法（LM），其雅可比系统规模小（≤ 4 参数），阻尼项保证稳定。

**假设与局限**：普通最小二乘假设残差独立同分布、方差齐性；R² 不是"拟合好坏"的唯一标准（不同模型不可直接比较）；线性化回归（指数/对数/幂）的 R² 是在变换后空间的值；外推超出数据范围不可靠。

## 3. 直方图与核密度估计

- **分箱数**：自动选择（**Freedman–Diaconis 规则**，四分位距为 0 时回退 **Sturges**），也可手动指定（1~200）；
- **KDE**：可叠加/关闭，核函数可选**高斯 / Epanechnikov**，带宽用 **Silverman 规则**自动选择；
- KDE 曲线按「密度 × n × binWidth」缩放，与直方图同为计数轴，可直接对照；
- 大数据：> 2 万样本时均匀抽稀到 2 万再做 O(n²) 直接求值，保证帧率。

## 4. 分布曲线

支持 10 种分布：**正态、t、卡方、F、二项、泊松、均匀、指数、Beta、Gamma**。

- **参数滑块**：拖动实时更新曲线（μ、σ、n、p、λ、自由度、α、β…）；滑块走 preview-提交模式——拖动不入历史，松手一整步撤销；
- **探针**：在画布上拖动（或点击）设置 x，琥珀色区域 = $P(X \le x)$，读数实时显示数值；
- **第二分布对比**：勾选后叠加第二个分布（绿色虚线）+ 其参数滑块；
- 概率密度/概率质量曲线蓝色实线，底轴显示分位数提示。

**数值实现**：正态 CDF 用 `erfc`（高精度分段连分式）；Gamma/Beta 不完全函数用级数 + 连分数（Numerical Recipes 路线）；`lnΓ` 用 Lanczos（g = 7）；t/卡方/F 的分位数由各自的逆函数迭代求得。验收对照：`P(X < 1.96) ≈ 0.975`、`q(0.975) ≈ 1.959964`、二项精确值、泊松 1e-9 级。

## 5. 模拟与概率演示（动画）

| 演示 | 内容 |
|---|---|
| **大数定律（LLN）** | 抛硬币频率收敛曲线（+ 0.5 参考线），增量累加不重算历史 |
| **中心极限定理（CLT）** | 样本均值直方图趋于正态（叠加参考曲线） |
| **蒙特卡洛求 π** | 撒点动画 + π/4 估计（保留最近 3000 个可视化点） |
| **自助法（Bootstrap）** | 对当前数据第 1 列重抽样，均值分布演示 |
| **随机游走** | 2D 三条轨迹同步延伸 |

播放/暂停/重置（重置 = 新种子）；速度与目标样本量可调；随机源为 mulberry32，**同种子结果可复现**（单测验证）。

## 6. 描述统计面板

选列后显示：**均值、中位数、标准差、方差、最小/最大、四分位数（Q1/Q3 与 IQR）、偏度、峰度**，以及 **SVG 箱线图**（1.5×IQR 离群点标出）。

- 方差/标准差为**样本口径**（分母 n−1）；
- 偏度/峰度为**修正版本**（小样本无偏系数）；
- Spearman ρ 用**平均秩**处理并列值。

## 性能与限制

| 项目 | 现状 |
|---|---|
| 10 万行 CSV 解析 | 单测验证 < 3 秒（异步分片，UI 不冻结） |
| 散点 10 万点渲染 | Canvas 单遍绘制（含回归线/残差模式），无 DOM 逐点 |
| 回归 10 万点 | < 1 秒（QR 为 O(nk²)，k ≤ 9） |
| 模拟帧 | 每帧固定步数 × 速度，历史增量更新，rAF 驱动 |

**明确不做**（v0.7 范围外）：假设检验（t 检验/方差分析）、多元回归、时间序列、贝叶斯推断；统计图当前仅支持 **PNG 导出**（SVG/TikZ 面向曲线与图）。
