# 采样算法原理（v0.3）

> 代码位置：`src/render/samplers/`（`adaptive.ts` / `parametric.ts` / `implicit.ts`）。
> 本页解释**为什么这样设计**与误差准则；验收对照见 [tests/benchmark/pathological-functions.md](../tests/benchmark/pathological-functions.md)。

## 一、为什么不用等距采样

等距取 1000 个点的失败模式（规格原文列举）：

- 曲率大的地方点不够密 → 画成折线；
- 平坦的地方浪费点；
- `tan(x)` 渐近线两侧被连成一条竖直长线；
- `sin(1/x)` 在 0 附近"一团糊"。

因此本实现采用**递归细分 + 屏幕空间误差准则 + 不连续检测**（与 JSXGraph / Gnuplot 的成熟做法同路）。

## 二、显函数自适应采样（`sampleExplicit`）

### 1. 种子点（屏幕空间均匀）

先在可视范围内按**屏幕空间**均匀取种子点（间距 ≈ 12 CSS 像素；对数坐标下即按十倍程均匀）。
屏幕空间而非数学空间，保证任意缩放下种子分布与像素密度一致。

### 2. 递归细分（误差准则）

对相邻两点 `(x₀,f₀) (x₁,f₁)`：

1. 取中点 `xₘ`，计算屏幕上中点偏离弦的**垂距** `d`；
2. `d > 容差（0.15–1.5px，随精度档位）` 且弦长 > 1px → 二分两半继续递归；
3. 否则收敛，输出折线段。

亚像素弦（< 1px）不再细分：`sin(1/x)` 在 0 附近振荡频率无限升高，
靠这条规则在像素分辨率处自然停止，配合**最大递归深度**（10–18，随档位）双重保险。

### 3. 不连续检测（本版最难的部分）

相邻种子点的屏幕纵向间距超过 **1 个视口高度**时，判定为"疑似跳变"，
二分定位跳变位置（收敛到 0.25px 或 60 次迭代），然后在跳变点处求值分类：

| 跳变点求值结果 | 判定 | 处理 |
|---|---|---|
| `NaN`（值本身缺失，如 `abs(x)/x` 在 0） | 真间断 | **断开，不连线** |
| `±Infinity`（如 `1/(x²-1)` 在 ±1） | 垂直渐近线 | **断开**，记录 x（渲染为红色虚线） |
| 有限但**数值巨大**（离视口中心 > 20 个视口高度，如 `tan(π/2)` ≈ 1.6e16） | 垂直渐近线 | 同上 |
| 有限且量级正常（如 `floor` 的整数台阶） | 有限跳变 | **垂直接线**（台阶处垂直、不斜切) |

> **关键设计**：渐近线判定不能只问"值是否 Infinity"——`tan(pi/2)` 在双精度下返回 1.6e16
> 而非 Infinity（规格"风险与陷阱"原文）。因此以**跳变点的实际求值结果**分类：
> 在 `abs(x)/x` 的 0 处得到 NaN、在 `tan` 的 π/2 处得到"巨大有限值"、
> 在 `floor` 的整数处得到"正常有限值"，三条路径自然分开。

### 4. 域边界（单端非有限）

`sqrt(x)` 在 x<0 为 NaN、`ln(x)` 在 x≤0 为 NaN：向边界二分"行进"，
只保留有限侧，逼近到像素精度为止（如 `sqrt` 的绘制起点距 0 小于 1e-3 个单位）。

### 5. 三重上限（防御病态输入）

| 上限 | 值 | 防御对象 |
|---|---|---|
| 递归深度 | 10–18（随精度） | `sin(1/x)` 无限细分 |
| 最小弦长 | 1px | 亚像素振荡 |
| 单次求值预算 | 120,000 次 | 一切意外情况（超预算即停止细分） |

## 三、参数方程与极坐标（`sampleParametric` / `samplePolar`）

与显函数同源：种子 + 递归细分，区别：

- 不假设 x 单调——准则改为**屏幕空间中点到弦的垂距**（对任意形状曲线都成立）；
- 任一分量非有限（或屏幕投影失败，如 log 域外）→ 向有效区间"行进"后断开；
- 种子数按参数跨度伸缩（128 个 / 2π，上限 1024），长跨度（多圈螺旋）自动加密；
- **极坐标 r = f(θ)** 直接转换为参数方程 `(r·cosθ, r·sinθ)` 后复用同一采样器。

曲线渲染器缓存采样结果（键 = 表达式 + 精度 + 视图 + 画布尺寸），视图不变则零采样开销；
视图变化时整条曲线重新采样（见性能验收：单曲线 < 16ms、10 条 < 33ms）。

## 四、隐函数：固定网格 Marching Squares（`sampleImplicit`）

- 把可视范围切成网格（单元 4–16px，随精度档位），采样每个角点的符号；
- 16 种角点符号组合查表生成短线段，交点在单元边上线性插值；
- 两种歧义组合（对角同号）用**单元中心值**决定连通性；
- 任一角点非有限 → 跳过该单元（已知限制）。

**已知限制（规格明确接受）**：固定网格会漏掉小于网格步长的细结构；
不做自适应细化（那是 v0.4+ 的可选项）。默认 8px 单元时，
圆/双曲线/心形等常规曲线质量与 JSXGraph 基准一致。

## 六、性能设计要点

1. **编译闭包**：表达式经 v0.2 引擎编译为 JS 闭包（`compile()`），单点求值 ≈ 百纳秒级；
2. **复用作用域对象**：热路径不分配临时对象（`scope.x = x` 复用）；
3. **屏幕空间种子**：与像素密度对应，减少无效求值；
4. **采样缓存**：视图/表达式未变时不重算；
5. **屏幕坐标钳制**：±1e6px 之外的坐标直接钳制，避免 canvas 极端值精度问题。
