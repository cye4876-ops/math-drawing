# 技术选型与开源生态清单

> 本文档记录**已核实**的选型决策及其理由。所有版本号核实于 2026-09 至 2026-10。
> 原则：**依赖尽量少，参考尽量多**。开源生态对本项目最大的价值不是省代码量，而是提供客观的对错标准。

---

## 一、核心技术选型

| 项目 | 选择 | 理由 |
|---|---|---|
| 语言 | **TypeScript** | 数值与 UI 统一，类型安全对数学库尤其重要 |
| 构建 | **Vite** | 快、零配置、静态输出 |
| 测试 | **Vitest**（单元）+ **Playwright**（交互） | 解析器与数值算法必须可测 |
| UI 框架 | **Svelte 5**（纯 Vite，不用 SvelteKit）+ 自定义面板 | 体积小、细粒度控制，且不与自研渲染层冲突（见 OPEN-QUESTIONS D12） |
| 数学排版 | **KaTeX** | 比 MathJax 快一个量级 |
| 渲染 | **自研 Canvas 2D** | 自适应采样、多边形填充、命中检测必须自己控 |
| 状态 | 单一 store + 撤销/重做栈 | 画图工具没有 Ctrl+Z 会很难用 |
| 后端 | **无** | 纯静态部署，数据留本地 |

---

## 二、分层渲染架构（开局即定，事后重构代价极大）

这是整个项目最重要的架构决定。

| 层 | 技术 | 承载内容 | 理由 |
|---|---|---|---|
| **Canvas 层** | Canvas 2D | 坐标网格、函数曲线、填充区域、图论的边（可能上千条）、3D 降级视图 | 每秒刷新 6 万点无压力 |
| **DOM 覆盖层** | SVG / HTML | 可交互节点、标签、控制点、滑块、游标 | 每个元素自带事件，拖动天然顺滑 |
| **文本层** | KaTeX | 公式标签、坐标轴刻度标注 | 排版质量 |

**判定规则**：
- 数量可能超过 2000 → Canvas
- 需要独立鼠标事件 → DOM
- 静态文本 → 按数量决定

**注意**：Canvas 层需自行实现命中检测（空间索引或反向遍历）。这是选 Canvas 的代价，接受。

## 三、运行时依赖（最终只有 4 个）

| 库 | 版本 | 许可证 | 用于 | 说明 |
|---|---|---|---|---|
| **KaTeX** | 最新稳定 | MIT | v0.3 起全程 | 公式排版 |
| **graphology** + 生态 | — | MIT | v0.5 图论 | 纯数据层 + 算法；ForceAtlas2 **带 WebWorker**、Louvain、shortest-path、metrics |
| **three.js** | 当前主版本 | MIT | **仅 v0.8** | 3D 曲面；**不要提前引入** |
| **nerdamer** | 2.0.0-rc（Apache-2.0） | — | **仅 v0.9** | 符号计算**对照**，见下方警告 |

### 关于 nerdamer 的重要警告

- 稳定版 `1.1.13` 停在 **2021-11**，五年未更新
- 作者于 **2026-09 重启**，TypeScript 全量重写，连发 `2.0.0-rc.1` / `rc.2`，许可证从 MIT 改为 **Apache-2.0**
- **用法**：v0.9 做**差分测试**——同一批表达式分别跑 nerdamer 与自研实现，比对结果。它准的地方参考其算法，它错的地方（CAS 在边界情况出错是常态）用自研规则覆盖
- **不允许**让它成为符号计算的唯一实现

## 四、参考实现（读代码，不做依赖）

这部分才是真正的高价值区——这些项目包含积累数十年的数值算法与交互设计。

| 项目 | 技术栈 | 许可证 | 借鉴什么 |
|---|---|---|---|
| **JSXGraph** | JS，稳定 `1.13.3` | **MIT 或 LGPL-3.0-or-later** | **自适应采样、渐近线检测、间断点处理**的首要对照物 |
| **Matplotlib** | Python | PSF-based（类 BSD） | **刻度选择算法**（`ticker.py`）。投入产出比最高的抄写对象 |
| **Graphviz** | C | EPL | **分层布局**（Sugiyama 算法）。v0.5 的 DAG 布局直接参考 |
| **SymPy** | Python | BSD-3 | 符号规则 + **数千个测试用例**可作 v0.9 回归集 |
| **Gnuplot** | C | 自定义开源 | 采样策略；纯 C 老代码，原理比 JS 抽象层更清晰 |
| **GNU Octave** | C++ | GPL-3.0 | 数值计算参考 |
| **GSL** | C | GPL | 求根、积分、特殊函数的标准算法（照它写 TS，不链接） |
| **Manim** | Python | MIT | 数学动画场景模型，v1.0 教学演示参考 |
| **Asymptote** | C++ | GPL-3.0 | 矢量输出精度处理，v0.6 导出参考 |
| **SageMath / Maxima** | Python / Lisp | GPL | CAS 算法选型文档比代码更有价值 |
| **GeoGebra** | — | **专有（非开源）** | **只能观察行为，不能抄代码** |
| **Desmos** | — | **专有** | 同上；采样与性能是行业天花板，值得逆向观察 |

### 为什么把 JSXGraph 当基准而非依赖

1. **在它之上做，最后交付的是"一个 JSXGraph 皮肤"**。而图论算法动画、3D、Notebook 它都不管，会卡在未暴露的扩展点上
2. **体积**：npm 包解包后 **70–80 MB**（含示例与测试）
3. **它自带完整渲染管线**，会与自研渲染层打架——两套坐标变换、两套命中检测、两套缩放语义
4. **许可证**：LGPL 分支下修改源码再闭源分发会违规（选 MIT 分支可规避）

**正确用法**：同一批病态函数分别在我们和 JSXGraph 上跑，肉眼比对。**追平即合格，超过即优秀。**

## 五、底层工具链（何时才需要）

| 工具 | 用途 | 引入时机 |
|---|---|---|
| **Rust + wasm-bindgen / wasm-pack** | 重计算编译为 WASM | **v0.8 隐式曲面、v0.9 大规模符号运算算不动时**再上 |
| **Emscripten** | C/C++ → WASM | 需要复用 GSL 等 C 代码时 |
| **WebGPU / WGSL** | 下一代图形 API | v0.8 之后若 WebGL 成为瓶颈 |

> **明确建议：v0.1–v0.7 不要碰 WASM。** 纯 TypeScript 在 60fps 下能画 10 万点，先用满这个额度。过早引入 Rust 会让构建链复杂度翻倍，收益要到很后面才出现。

## 七、标准与格式（最被低估的借力点）

| 标准 | 用途 | 应用版本 |
|---|---|---|
| **LaTeX / PGFPlots / TikZ** | 论文插图 | **v0.6 TikZ 导出接入此生态**——外部杠杆最大的一处 |
| **MathML** | 数学标记语言 | 公式导入导出，唯一中立格式 |
| **SVG** | 矢量输出 | 浏览器原生，零依赖 |
| **CSV / JSON** | 数据交换 | v0.7 统计导入 |
| **OEIS** | 整数序列数据库 | v0.9 数论可视化可对接 |
| **OpenMath / Content MathML** | 语义化数学 | 需要 CAS 间交换表达式时才用 |

**TikZ 这条线值得强调**：LaTeX 生态里的 `pgfplots`（函数图）与 `tikz-network`（图论）已经把"数学图形如何用矢量描述"做透了。v0.6 的导出本质是**生成它们的代码**——我们不需要发明矢量格式，直接输出到成熟生态，用户拿去就能进论文。

## 八、许可证红线

| 许可证 | 使用方式 |
|---|---|
| **MIT / BSD / ISC / Apache-2.0** | 自由使用，保留版权声明 |
| **LGPL-3.0** | 作为库动态调用可以；**修改源码后闭源分发违规**。若需闭源/商用，走 MIT 分支 |
| **GPL / AGPL** | **不引入为依赖**。可作为算法参考，独立重写 |
| **专有（GeoGebra / Desmos / MATLAB / Mathematica）** | **只能观察行为，不能抄代码** |

**必须执行**：v0.1 就把许可证扫描加入 CI（`license-checker` 之类），扫描整棵依赖树。等到 v1.0 要发布时才发现某个传递依赖是 GPL，代价极大。

## 九、明确不用的东西

| 东西 | 原因 |
|---|---|
| **mathjs** | 体积大，且解析行为不可控——我们需要完全掌控 AST |
| **D3（整体）** | 坐标系与数学坐标系相反，反而绕。**只借它的标度与刻度算法** |
| **JSXGraph / Cytoscape.js / Sigma.js 作为核心依赖** | 各自自带渲染管线，与自研层冲突 |
| **Electron** | 体积大；若需桌面版用 Tauri |
| **Wolfram Engine** | 许可证限制商用，核心不可控 |
| **各类"Desmos 克隆"小项目** | 多为调库的皮，读完学不到东西 |
