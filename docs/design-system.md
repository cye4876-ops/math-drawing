# Math Drawing 设计系统（v2.0 重设计）

> 由 [UI UX Pro Max](https://uupm.cc) 设计系统生成器产出（技能安装于 `.github/prompts/ui-ux-pro-max/`），
> 结合本产品（数学可视化 + 教学 Notebook）的定位裁剪。**原则：只改视觉，不动功能与结构（testid/交互/布局语义保持）。**

## 1. 方向定案

| 维度 | 选择 | 依据 |
|---|---|---|
| 风格 | **Dark Mode (OLED) + 数据工具风** | 生成器推荐（可视化/分析类）；深色背景对彩色曲线/曲面图形对比度更佳；长时间使用护眼 |
| 主色 | `#3B82F6`（深底可读性优先，hover `#60A5FA`） | 交互蓝，沉稳不抢图形颜色 |
| 强调/CTA | `#22C55E`（运行绿） | 「计算/运行」语义；点缀数据可视化 |
| 背景/卡片 | `#0F172A` / `#1B2336` | OLED 深底 + 分层卡片（Dimensional Layering 轻量做法） |
| 文字 | `#F8FAFC` 主 / `#94A3B8` 弱 | 对比度 ≥ 4.5:1 |
| 边框 | `#475569`（弱化为半透明 rgba 亦可） | 低对比分隔，避免网格感 |
| 等宽字体 | `JetBrains Mono`（降级 ui-monospace/Consolas） | 表达式、数字、公式的「精确感」 |
| 正文字体 | 系统栈（`-apple-system, "Segoe UI", "Noto Sans SC"`） | 中文稳定 + 离线可用（不引入 Google Fonts 运行时依赖） |

**反模式（明确避免）**：纯黑 `#000` 背景（层次丢失）、高饱和多色强调（与图形颜色打架）、慢动画（>300ms 过渡）、emoji 图标。

## 3. 组件规范（实施检查点）

- **按钮**：圆角 8px；hover 亮一档（150ms 过渡）；focus 可见 ring（`outline: 2px solid accent`）；选中态用 accent 底色/描边。
- **输入/下拉**：底色比面板深一档（`#151E30`），边框低对比，focus 边框 accent + ring。
- **卡片（单元格/图表卡）**：面板色 + 1px 边框 + 柔和阴影 `0 1px 3px rgba(0,0,0,.4)`；圆角 10-12px。
- **工具栏/状态栏**：略深于背景（`#0B1220`）建立层级；分组间用间距而非重分割线。
- **表格**：斑马纹用 `rgba(255,255,255,.03)`；表头文字弱色大写间距。
- **滚动条**：细化宽 10px、滑块 `#334155`。
- **过渡**：交互态 150-200ms；尊重 `prefers-reduced-motion`。
- **图标**：不使用 emoji 作为图标（本产品按钮以文字为主，保持）。

## 4. 交付前检查清单（来自技能规范）

- [ ] 所有可点击元素 `cursor: pointer`；hover/focus 态齐全
- [ ] 深色下文字对比 ≥ 4.5:1；focus 键盘可达
- [ ] `prefers-reduced-motion` 生效
- [ ] 响应式 375 / 768 / 1024 / 1440 不破版（本产品桌面优先，最小宽度可用即可）
- [ ] 离线字体可用（系统栈）；无新增加载时外部依赖

## 5. 实施批次（保留功能不变）

| 批次 | 范围 | 验收 |
|---|---|---|
| **1（外壳）** | `app.css` 令牌 + 全局元素（body/按钮/输入/滚动条）+ Toolbar/StatusBar/侧栏面板容器样式 | 深色外壳自洽；`pnpm dev` 目视 + typecheck/lint |
| **2（组件）** | 各 Svelte 组件 scoped 样式中的硬编码浅色（曲线列表/图面板/统计/3D/进阶/Notebook 卡片/导出面板/插件区） | 全模式截图自查无浅底漏块 |
| **3（画布主题）** | grid/axis/标注颜色（grid-renderer 等硬编码色收敛为主题常量）；导出 PNG/SVG 保持白底不变（导出物面向打印） | 截图对照；导出回归 |
| **4（回归与发布）** | 全量单测 + e2e 161 + 浏览器全模式走查；提交 `feat: UI 重设计`，push 自动部署 | CI 双绿 + 线上目视 |

> 注：导出物（PNG/SVG/TikZ/HTML/LaTeX）**保持浅色**——它们是「打印/分享」语义，不做深色化。
