# 超图与彩虹实验室（v3.4 / v3.5）

> 入口：顶栏「超图与彩虹」模式（`?mode=hyper`）。
> 两个子视图：**超图实验室**（结构、四视图、精确不变量、Property B、JSON 编辑）与
> **彩虹 / 反拉姆齐**（彩虹子图搜索、Gallai 检测、小 n 反拉姆齐、超图彩虹匹配）。

## 一、为什么做这两个模块

调研 GitHub 生态后的定位：

| 方向 | 现有开源 | 我们的差异 |
|---|---|---|
| 超图分析 | HyperNetX、HypergraphX、XGI 等 Python 研究库，功能成熟但以 Notebook/静态图为主 | 浏览器内**四视图联动 + 点击选中 + 见证高亮**，面向学习与反例核验 |
| 极值图论 | nauty/Traces（穷举）、flagmatic/FlagSOS（旗代数）、Sage | 不追求研究级证明，专注**小 n 可交互计算与证书**；v3.6 已新增独立的「极值计算台」子标签（ex(n,H) / Turán / Ramsey / 3-一致超图），详见 [extremal-lab.md](extremal-lab.md) |
| 彩虹图/反拉姆齐 | 几乎无通用开源库（仅零散脚本） | **彩虹副本枚举 + 反拉姆齐小 n 穷举 + 见证着色应用** |

我们**没有拷贝**上述项目代码；算法按定义独立实现，仅把 nauty/Sage/networkx/HGX 作为离线基准与设计参照。

## 二、超图实验室（v3.4）

### 数据模型

- 顶点：`{ id, label, color }`；超边：`{ id, label, members[], color, weight }`；
- 紧凑 JSON：`{ "name": "K₅³", "n": 5, "edges": [[0,1,2], ...] }`；
- 完整 JSON：显式 `vertices` 与成员 id，保留标签、颜色、权重；
- 校验：顶点数 1–12、超边数 ≤ 120、成员范围/重复/空边/重复超边均有中文错误。

### 预设族

| 族 | 说明 |
|---|---|
| 完全 r-一致 `Kₙʳ` | 全部 r-子集；默认 n=5,r=3（10 条超边）；n=6 时 20 条 |
| Fano 平面 | n=7、7 条三元线；线性、正则、自对偶、不可 2-着色 |
| 松三角形 | `012, 234, 450`（n≥6）；线性但非正则 |
| 紧循环 | `i,i+1,i+2`（模 n，n≥4） |
| 星形 | 全部包含顶点 0 的 r-子集 |
| 随机 r-一致 | 确定性 LCG（固定种子可复现；“随机换种”递增种子） |
| 空超图 | 保留孤立点 |

### 四视图

1. **集合视图**：顶点圆环 + 超边凸包气泡（2 点用胶囊、1 点用圆晕）；点击顶点/超边选中；
2. **关联二部图**：左顶点、右超边（方块），连线为关联；
3. **2-截面**：灰线连接共超边的顶点对，气泡保留原超边归属；
4. **线图 L(H)**：节点 = 超边，相交即连边。

选中顶点显示度与关联超边；选中超边显示大小、成员与权重。

### 精确不变量

| 量 | 定义 | 实现 |
|---|---|---|
| 度序列 | 顶点所在超边数 | 线性扫描 |
| 秩 / 一致 | 最大边大小 / 所有边同大小 | 线性扫描 |
| 线性 | 任意两超边交 ≤ 1（最大共度 ≤ 1） | 共度矩阵 |
| 正则 | 所有顶点度相同 | 度序列 |
| 连通分量 | 同一超边内顶点连通；孤立点单独分量 | 并查集 |
| 匹配数 ν | 最大两两不交超边集 | 位掩码回溯 + 剪枝（n≤20） |
| 横截数 τ | 最小击中所有超边的顶点集 | 复用互补弱独立集：τ = n − α |
| 独立数 α | 最大不含完整超边的顶点集 | 位掩码回溯 |
| Property B | 是否存在无单色超边的 2-着色 | 按度排序回溯 + 颜色对称固定 + 单色剪枝 |
| 对偶 | 顶点 ↔ 超边互换 | 关联转置；孤立原顶点不产生空超边 |
| 2-截面 / 线图 | 共边顶点对 / 相交超边对 | 去重集合 |

“标记最大匹配 / 最小横截 / Property B 见证” 会把见证直接高亮到画布；`载入对偶图` 可继续观察对偶结构。

## 三、彩虹与反拉姆齐（v3.5）

### 彩虹子图

模式：`P₃/P₄/P₅`、`C₃/C₄/C₅`、`2K₂/3K₂`、`K₃/K₄`。
搜索采用回溯，保证：

- 顶点不重复（匹配为边不交）；
- 所有边颜色互不相同；
- 路径/圈消除反向与旋转重复（起点最小、第二点 < 最后点）；
- 返回边集见证，可逐条点击并在画布高亮。

### Gallai 着色

无彩虹三角形 ⇔ Gallai 着色。面板可直接检测当前着色，并统计彩虹三角形数量；
「全不同色」Kₙ 应有 C(n,3) 个彩虹三角形（K₅ = 10）；而按 `min(i,j)` 上色的 Gallai 构造
使用 n−1 种颜色且不含彩虹三角形。

### 反拉姆齐 ar(n,H)

对 Kₙ 的边着色做**受限增长串**（颜色规范化）穷举，剪枝条件：

- 已出现彩虹 H 的分支立即剪掉；
- `当前颜色数 + 剩余边数 ≤ 历史最优` 剪枝；
- 节点/时间预算保护；预算耗尽时明确标注“下界”。

已知结果（Gallai 定理）对三角形直接给出闭式：`ar(n,K₃) = n−1`，并输出见证着色；
其它模式在 n ≤ 6 内穷举，n=6 可能受预算限制（结果会标注未完成）。

独立 Python 基准（`tools/lab-oracle/gen-v34-oracles.py` → `v34-oracles.json`）核验值：

| n | P₃ | P₄ | C₄ | 2K₂ | K₄ | C₃ |
|---|---|---|---|---|---|---|
| 4 | 1 | 3 | 4 | 3 | 5 | 3 |
| 5 | 1 | 2 | 5 | 1 | 7 | 4 |
| 6 | — | — | — | — | — | 5 |

超图基准（同一 oracle）：

| 超图 | n | m | ν | τ | α | Property B |
|---|---|---|---|---|---|---|
| K₅³ | 5 | 10 | 1 | 3 | 2 | 否 |
| Fano | 7 | 7 | 1 | 3 | 4 | 否 |
| 松三角形 | 6 | 3 | 1 | 2 | 4 | 是 |

### 超图彩虹匹配

当前超图的边颜色参与搜索：选择两两不交且颜色互异的超边集合，支持“目标大小”与“最大”两种查询；
n ≤ 12 时精确求解并给出超边见证。

## 四、已知限制

- 超图实验室顶点数 ≤ 12、超边数 ≤ 120；精确不变量为指数级算法，规模由上限保护；
- 彩虹搜索使用简单图语义：平行边只取第一条参与团搜索；路径/圈搜索保留不同边记录；
- 反拉姆齐 n ≤ 6；n=6 且非三角形模式可能触发预算，结果会标注“下界/未完成”；
- 画布为独立视图，不进入文档保存/分享；导出可用面板 JSON 或截图；
- 未实现旗代数（flag algebra）与 nauty 式规范生成；v3.6 的极值计算台使用内嵌 n≤7 图集（见 [extremal-lab.md](extremal-lab.md)），更大 n 仅提供 Turán 构造与公式。
