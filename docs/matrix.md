# 矩阵分解模块（v2.3）

> 入口：工具条「矩阵」标签（`?mode=matrix`）。
> 与图论同级的独立模块：矩阵输入 → 数值分解 → **矩阵结果卡 + 实时几何可视化**。

---

## 一、功能总览

| 运算 | 算法 | 输出与验证 |
|---|---|---|
| **LU 分解** | 部分主元高斯消去（Doolittle） | `P·A = L·U`；置换矩阵 P、单位下三角 L、上三角 U；主元近零标记奇异；重构残差 |
| **QR 分解** | Householder 反射 | `A = Q·R`；**R 对角取正**（标准教材规范，符号归一通过翻转 Q 列实现）；Q 正交（QᵀQ = I）与重构双验证 |
| **相似对角化** | Faddeev–LeVerrier + **重根抛光 + 逆迭代 Rayleigh 商精化** + RREF | `A = P·D·P⁻¹`；特征多项式本体（如 λ²−4λ+3）、特征值（含复）、代数/几何重数、P / D / P⁻¹；残差验证 |
| **行列式·迹·秩·逆** | LU 内核（**尺度相对容差**） | det / tr / rank 数值，逆矩阵（奇异时报告不可逆）；极小行列式保留科学计数法（如 diag(1e-6,1e-6) → 1e-12） |

**教学化提示**：

- **复特征值**（如旋转矩阵）：说明「在 ℝ 上没有特征向量基，不能实对角化」，并**依据复数零空间给出 ℂ 上是否可对角化**（几何重数 = 代数重数）——不再默认“复数域上仍可对角化”；
- **缺陷矩阵**（如剪切 [[1,1],[0,1]]）：几何重数 < 代数重数 → 特征向量不足 n 个，不可对角化（ℝ 与 ℂ 上均不可）。

## 二、几何可视化（画布）

- 实时显示当前矩阵 A（2×2 及以上取**左上 2×2 块**）对**单位正方形**与**基向量**的变换：
  - 灰色虚线 = 原始单位正方形；蓝色平行四边形 = 列向量 a₁、a₂ 张成的像；
  - 暗色箭头 = e₁、e₂；蓝 = a₁ = A·e₁；绿 = a₂ = A·e₂。
- 相似对角化完成后叠加**特征方向**（橙色虚线 + λ 标注）——直观展示「特征向量方向不变、只被拉伸 λ 倍」；
- 复特征值情形在画布上说明「无实特征方向（旋转分量）」。

## 三、数值内核（`src/matrix/linalg.ts`）

| API | 说明 |
|---|---|
| `matmul / transpose / matVec / identity / maxAbsDiff` | 基础运算与残差度量 |
| `luDecompose / determinant / inverse / rank` | LU 内核族（部分主元；行交换时同步交换 L 已算乘子） |
| `qrDecompose` | Householder：向量作用 + Q 右累积 + 对角符号归一 |
| `characteristicPolynomial` | Faddeev–LeVerrier：`Mₖ = A·Mₖ₋₁ − cₖI`，返回降幂系数 `[1, −c₁, …, −cₙ]` |
| `polyRoots` | Durand–Kerner 复数迭代（初值 0.4+0.9i 幂次；800 次上限；微小虚部自动抹零） |
| `nullspace` | RREF 基础解系（相对容差防噪声） |
| `eigenDecompose` | 特征值聚类去重 + **同一特征空间内**正交化（跨空间投影会破坏特征向量性质）+ 对角化判定 + 残差 + 逆迭代/Rayleigh 精化（重根如 I₄ 收敛到精确值） |
| `rank` / `rankTolerance` | 数值秩：相对容差 1e-9 × max\|aᵢⱼ\|（与矩阵尺度相关，1e-10·I₂ 秩为 2） |
| `cleanNumber` | 噪声抹零（显示与判零统一） |

## 四、已验证事实（单测对照）

- `det [[1,2],[3,4]] = −2`；`det diag(2,3,4) = 24`；奇异矩阵 det = 0、逆为 null；
- LU 四例（含 `[[0,1],[1,0]]` 需换行、经典 3×3）重构 `P·A ≈ L·U`（残差 < 1e-8）；
- QR 三例：`QᵀQ = I`、`Q·R ≈ A`、R 上三角；`R` 对角 3.1623 / 0.6325（手算对照）；
- 特征多项式：`[[2,1],[1,2]] → λ²−4λ+3`、`[[1,2],[3,4]] → λ²−5λ−2`、`diag(1,2,3) → λ³−6λ²+11λ−6`；
- 复根：`λ²−5λ−2` 精确、`λ²+1 → ±i`；
- 相似对角化：对称 2×2（λ=1,3）、一般 2×2（(5±√33)/2）、对称 3×3（2、2±√2）、三对角 6 阶（2+2cos(kπ/7)，六个特征值全部吻合）残差 < 1e-8；旋转不可实对角化、剪切缺陷。
- **v2.9 固定回归样例**：单位阵 I₃/I₄（全部 λ=1、可实对角化）、Jordan 块（ℝ/ℂ 均不可对角化）、旋转矩阵（ℂ 上可对角化）、diag(1e-6,1e-6)（det = 1e-12、秩 2、逆一致）——已加入每次发布前的检查清单。

## 五、已知限制

- 支持 2 ~ 10 阶；特征多项式为 O(n⁴) 系数计算（Faddeev–LeVerrier 在 n ≥ 8 时数值条件变差，仅建议教学规模使用；更大规模需特征值迭代算法如 QR 算法）；
- 相似对角化仅支持**实对角化**展示（复特征值给出提示而非复数矩阵输出）；
- Durand–Kerner 对重根收敛为线性（教学矩阵 800 次上限内足够）；
- 几何可视化取左上 2×2 块（更高阶的完整几何语义超出二维画布）；
- 未提供 SVD / Cholesky / 广义特征值（可作后续扩展，接口已按分解族组织）。
