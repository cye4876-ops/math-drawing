# 曲线输入与使用指南（v0.3）

> 表达式本身的语法（运算符、函数、常量等）见 [expr-syntax.md](expr-syntax.md)。
> 本文只讲**怎么画出图**。在线试试：`pnpm dev` 后打开 <http://127.0.0.1:5173/>。

## 一、四种曲线怎么输入

右侧「曲线」面板选择类型 → 输入表达式 → 点「添加曲线」（或按回车）。

| 类型 | 面板标签 | 输入形式 | 示例 |
|---|---|---|---|
| 显函数 | `y = f(x)` | 直接输入 f(x)（不用写 `y=`） | `sin(x)`、`x^2/4 - 1`、`{x<0: -x, x>=0: x}` |
| 隐函数 | `F =` | 输入 F(x, y)，画 **F = 0** | `x^2 + y^2 - 4`（圆）、`x^2 - y^2 - 1`（双曲线） |
| 参数方程 | `x(t)` / `y(t)` | 两个表达式，t 范围默认 **[0, 2π]** | `cos(t)` 与 `sin(t)`（单位圆） |
| 极坐标 | `r =` | 输入 r(θ)；变量写 `theta`（也可用 `θ`） | `1 + cos(theta)`（心形线）、`cos(2*theta)`（四叶玫瑰） |

小技巧：

- `2x`、`2sin(x)` 这种**隐式乘法**可以直接写；
- `pi`、`e`、`theta` 是内置常量/变量名（`π`、`θ` 亦可）；
- 表达式有语法错误时，该项下方会给出**带位置的中文提示**，修正前该曲线不会绘制；
- **不知道选哪种类型？** 选「**自定义方程（自动识别）**」（v3.1）：把方程原样粘进去（如 `x^2 + y^2 = 4`），面板会实时提示识别结果（显函数 / 隐函数 / 极坐标 / 参数方程）并自动归位——规则见下。

### 自定义方程（自动识别，v3.1）

打字或粘贴后**无需选类型**，面板根据写法自动识别（识别提示实时显示在输入框下方）：

| 写法 | 识别为 | 例子 |
|---|---|---|
| `y = f(x)` 或直接 `f(x)` | 显函数 | `y = sin(x) + a` |
| 含等号的 x/y 方程 | 隐函数（归一为 F = 左 − 右） | `x^2 + y^2 = 4` → 画 `x^2 + y^2 − 4 = 0` |
| 含 y 但无等号 | 隐函数 F = 0（原样） | `x^2 + y^2 - 1` |
| `r = f(θ)`（θ 或 theta） | 极坐标 | `r = 2*cos(3*theta)` |
| `x = f(t); y = g(t)`（**分号**隔开两段） | 参数方程 | `x = cos(t); y = sin(t)` |

细节：分号支持中文「；」，两段顺序任意；参数方程无需第二个输入框；全角等号「＝」自动归一；一个方程最多一个等号（多了会报错且不添加）。

**常用函数快捷按钮**（输入框下方）：`sin()`、`cos()`、`tan()`、`ln()`、`exp()`、`√`、`|x|`、`x²`、`π`。
点击后在光标处插入片段；函数类按钮会自动把光标放到**括号内**，直接输入参数即可（如点 `sin()` → 键入 `2x` → 得到 `sin(2x)`）。

## 二、曲线管理

每条曲线可单独设置（列表项从左到右）：

- **颜色**：点击色块修改（新曲线按色环自动分配，相邻颜色可区分）；
- **名称**：直接编辑（默认取表达式原文）；
- **显示/隐藏**：勾选框；
- **↑ ↓**：调整绘制顺序（影响叠放）；
- **✕**：删除；
- **表达式**：直接修改（回车/失焦生效）；
- **线型**：实线 / 虚线 / 点线；
- **精度**：低 / 较低 / 标准 / 较高 / 高（采样容差与递归深度；曲线抖动或有细结构时调高）。

### 标记点

右侧栏「标记点」面板：

- **输入坐标添加**：填 x、y（支持 `pi/2`、`-e` 等常量表达式）→ 「添加」（或按回车）；
- **列表**：显示全部标记点（等宽字体坐标），数量多时**上下滚动**；
- **✕**：删除标记点（可撤销）；
- 工具条「添加标记点」按钮仍可一键在当前视图中心添加。

## 三、视图操作

| 操作 | 方式 |
|---|---|
| 缩放 | 滚轮——**以视图中心为锚点**（缩小时坐标轴原点始终留在画布中央）；触屏**双指捏合**以两指中点为锚点（v3.1），可配合单指拖拽无缝平移 |
| 触屏放大 | 画布上**双击**（320 ms / 28 px 内两次轻触）以触点为锚点放大 1.6×（v3.1） |
| 平移 | 拖拽画布（空白处） |
| 坐标轴 | **固定在 x=0 / y=0，不可拖动**（工具条「坐标轴」开关可隐藏/显示） |
| 精确输入 | 工具条「视图设置」→ 填 `x ∈ [a, b]`、`y ∈ [c, d]` → 「应用」 |
| 等比模式 | 工具条「等比」开关：开启后 x/y 比例锁定（`x^2+y^2=4` 看起来是正圆） |
| 坐标类型 | 工具条「坐标」：直角 / 极坐标网格 / 对数（双轴 log₁₀） |

对数坐标注意：曲线只在定义域为正的区域绘制（负值处自动断开）。

## 四、保存与分享文档

- **导出 JSON**：把当前曲线 + 视图存成 `math-drawing.json`；
- **导入 JSON**：完整还原（导入前请先导出备份当前内容；导入后可 Ctrl+Z 撤回）。

## 五、快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+Z` | 撤销（曲线增删改、标记点；**视图缩放/平移不入历史**） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |

## 六、已知限制（v0.3）

- **隐函数**用固定网格算法（Marching Squares，默认 8px 单元）：
  比网格还细的结构（如 `sin(1/x)` 级别的自交细节）会漏画——这是规格接受的限制；
- 参数方程与极坐标的 t / θ 范围固定为 **[0, 2π]**（暂不支持自定义范围）；
- 极坐标「坐标类型」只改变**背景网格**（同心圆 + 射线），曲线本身仍按数值绘制。
